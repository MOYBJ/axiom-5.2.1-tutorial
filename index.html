关于本教程

这是一本什么样的教程#

本教程面向所有使用 Axiom 的《我的世界》建造者，从第一次安装到把工具组合成生产线，按「认识 → 安装 → 上手 → 分模块详解 → 实战」的顺序组织，既可以顺序通读，也可以当作操作手册按需查阅。

全书共 12 章与 1 个附录：第 1–3 章解决「装得上、进得去、会操作」；第 4–9 章按功能模块逐一讲解全部工具与窗口；第 10–12 章覆盖命令、配置、授权、实战工作流与常见问题；附录提供快捷键速查、术语中英对照与资料来源。

Axiom 会持续更新，界面与选项可能与本书描述存在细微差异，请以你实际使用的版本为准。

使用前提与合规提示#

本书中的操作默认你已经拥有可运行 Axiom 的《我的世界》Fabric 环境，并具备创造模式下的世界编辑权限。

第 1 章认识 Axiom

1.1　Axiom 简介#

1.1.1　文档定位#

欢迎来到 Axiom 文档，这是关于这款《我的世界》(Minecraft) 世界编辑全能工具的入门读物。Axiom 的目标是帮助你更快、更高质量地建造地形、植被（organics）与结构。该模组带来了创新的新工具与算法，同时通过实时客户端可视化改进了反馈回路，从而提升易用性。

1.1.2　Axiom 适合谁#

Axiom 易学难精，通过不同层级的复杂度，面向所有水平的 Minecraft 建筑者。对新手最友好的工具位于 Builder Mode（建造模式）；Editor Mode（编辑器模式）则包含更深入的工具，可与 Tool Masks（工具蒙版）组合使用以获得更高的复杂度。

第 3 章快速上手：10 分钟跑通全流程

本章不谈原理，直接带你走完一条最小可用路径：确认模组生效 → 认识三个入口 → 用建造工具搬一棵树 → 用编辑器模式做一个小地形 → 把成果存成蓝图复用。走完这一遍，你就能独立使用 Axiom 完成日常建造任务。

3.1　第 0 步：确认模组已经生效#

进入游戏后按 T 打开聊天栏，输入 /whynoaxiom 并回车。

  • 如果该命令返回了 Axiom 的正常状态信息，说明模组已正确加载。
  • 如果命令不存在或提示报错，说明模组没有加载成功：请回到「安装与首次启动」章节逐项核对 Fabric Loader、Fabric API 与 jar 存放位置。
  • 最直观的判据：创造模式世界创建后，快捷栏（Hotbar）的第 10 格会出现一个 Axiom 图标。没有图标就说明没加载。

3.2　第 1 步：记住三个入口#

Axiom 的全部功能都从下面三个入口进入，建议先花两分钟把它们按熟：

入口操作方式作用
上下文菜单（Context Menu）选中第 0–9 格热键栏，按住 左 Alt开关各项「能力（Capabilities）」、快捷栏交换器、飞行速度、工具箱
建造工具（Builder Tools）按 0 选中第 10 格，按住 左 Alt 并滚动鼠标滚轮切换工具移动、克隆、堆叠、拉伸、挤出、删除、设置对称
编辑器模式（Editor Mode）按 右 Shift 开 / 关大规模地形、绘制、雕刻、蓝图等专业工具集

三个入口的按键都可以在《我的世界》的「选项 → 控制」中修改（在该列表的 Axiom 分组内）。

3.3　第 2 步：练习一 —— 用建造工具搬动一棵树#

这是一个 3 分钟就能完成的练习，覆盖了建造工具最核心的交互方式。

  1. 选中工具：按 0 选中第 10 格，按住 左 Alt 滚动鼠标滚轮，切换到「移动（Move）」。
  2. 框出选区：用左键点击树干底部的第一个角点，再用右键点击对角方向的第二个角点。此时会显示一个大致的立方体选区。
  3. 用中键补全选区：中键不是选角点，而是选面。依次用中键点击树干其余几个面，把整棵树完整包进选区。
  4. 移动选区：滚动鼠标滚轮开始移动，屏幕会出现全息投影（hologram）预览结果。滚轮向上把选区推离你、向下把选区拉近你。按住 X、Y 或 Z 可强制只沿单个坐标轴移动。
  5. 调整朝向（可选）：Ctrl+F 按你面朝的方向翻转选区，Ctrl+R 让选区在 X、Z 轴上顺时针旋转 90°。
  6. 确认放置：右键确认，方块落地。
  7. 后悔药：Ctrl+Z 撤销，Ctrl+Y 重做。
提示小技巧：三格通用开关会显著影响结果——「保留原有方块（Keep Existing）」避免覆盖已有方块，「复制实体（Copy Entities）」决定是否连实体一起搬，「复制空气（Copy Air）」决定是否连空气一起搬。搬树、搬建筑时按需打开。

3.4　第 3 步：练习二 —— 在编辑器模式里推一个小山丘#

  1. 进入编辑器模式：按 右 Shift。此时你会看到顶部的主菜单栏、底部菜单栏，以及各个可停靠窗口。
  2. 切换视角：左键拖动旋转摄像机，Ctrl+右键 平移摄像机，Ctrl+左键 是围绕光标点的轨迹球旋转。
  3. 选工具：在 Tools 窗口选择「高程（Elevation）」（快捷键 E）或「画笔（Painter）」（快捷键 P）来堆地形；如果是给已有地形换材质，「画笔（Painter）」更合适。
  4. 调参数：在 Tool Options 窗口调整形状（Shape）、半径（Radius）等参数。按住 Ctrl 再点滑块可以直接输入精确数值；Ctrl+中键 可在视口中快速调整工具半径。
  5. 执行：把准星对准地面，按住右键刷（Use Tool 默认就是鼠标右键）。左键在编辑器模式中主要用于旋转视角，不要和「使用工具」混淆。
  6. 收尾打磨：切到「平滑（Smooth）」（快捷键 U）抹平生硬的堆叠；需要更自然时用「粗糙化（Roughen）」或「噪声画笔（Noise Painter）」（快捷键 O）加变化。
  7. 退出：再按一次 右 Shift 回到普通游戏界面。

3.5　第 4 步：把成果存成蓝图并复用#

  1. 用「框选（Box Select）」（快捷键 B）或「魔法选择（Magic Select）」（快捷键 M）选中你要保留的建筑。
  2. 按 Ctrl+C 把选区内容复制进剪贴板（Clipboard）。
  3. 按 Ctrl+P 打开「创建蓝图（Create Blueprint）」窗口：填写名称、作者、标签，并旋转生成一张便于识别的缩略图。
  4. 保存后，文件会写到 .minecraft/config/axiom/blueprints 目录下（可在配置文件中修改），扩展名为 .bp。
  5. 之后需要复用时，打开蓝图浏览器（Blueprint Browser），用名称或标签搜索，双击即可载入剪贴板，再按 Ctrl+V 粘贴到世界里。

蓝图可以直接把 .bp 文件发给同事，对方放进同样的目录就能使用——这也是团队共享建筑资产最简单的方式。

阶段目标建议重点阅读

一个实用建议：把每一类「你反复手做的操作」都尝试用工具或蓝图固化下来。Axiom 的价值不在于单次操作更快，而在于把重复劳动变成可复用的资产。

第 4 章建造模式（Builder Mode）

4.1　建造模式（Builder Mode）#

建造模式（Builder Mode）是对原版创造模式（Creative Mode）的增强。它加入了许多新功能，大幅减轻了传统建造方式中的繁琐操作，让建造变得更为轻松。

4.1.1　建造模式上下文菜单（Builder Context Menu）#

建造模式下的许多功能都可以通过上下文菜单来切换或访问。按住 左 Alt 即可打开该菜单。更多信息请参阅「上下文菜单（Context Menu）」章节。

4.1.2　建造工具（Builder Tools）#

在快捷栏（Hotbar）的右侧，你可以找到建造工具。这些工具非常简单直观，旨在用于结构建造/小规模建造的场景——在这些场景中，使用功能更强大的「编辑器模式（Editor Mode）」反而过于笨重。

要开始使用某个建造工具，滚动到第 10 格或按下按键 0。要切换到其他建造工具，按住 左 Alt 再滚动鼠标滚轮。

建造工具的三大主要按键绑定是左键、右键和中键。中键的功能与左键、右键类似，但它不是选择角点，而是用于选择面。

在使用选区时，诸如偏移量（offset）和尺寸（size）等有用信息会显示在快捷栏上方。

4.1.3　游戏玩法（Gameplay）#

当准星对准一个方块时按下 Ctrl+C，会复制该方块精确的 NBT 状态。被复制的方块属性会显示在物品的工具提示（tooltip）中。

在创造模式物品栏中搜索时，按下回车键会把列表中第一个方块放入你当前选中的快捷栏格。

4.2　建造工具（Builder Tools）#

本节目前可用的工具如下：

  • 移动（Move）
  • 克隆（Clone）
  • 堆叠（Stack）
  • 涂抹/拉伸（Smear）
  • 挤出（Extrude）
  • 删除（Erase）
  • 设置对称（Setup Symmetry）

适用于大多数建造工具的三个通用开关（flags）：

  • 保留原有方块（Keep Existing）
  • 切换是否阻止覆盖已存在的方块。
  • 复制实体（Copy Entities）
  • 切换移动选区时是否一并复制实体。
  • 复制空气（Copy Air）
  • 切换移动选区时是否一并复制空气（air）。

4.3　移动（Move）#

移动工具（Move）允许你改变一个长方体（cuboid）区域内方块和实体的位置。

4.3.1　创建选区（Creating Selections）#

要创建选区，首先用左键选择第一个角点，然后用右键选择第二个角点。你也可以用中键来选择面而不选择角点。这让选择那些本身没有明显棱边的方块变得容易得多。

4.3.2　移动选区（Moving Selections）#

当你对选区满意后，滚动鼠标滚轮即可移动它。此时会出现一个全息投影（hologram）来表示你要操作的选区。同时你还会看到不同的操作控件：使用中键可以把选区移动到你所面向的方向。

使用滚轮，可以按一格为单位微调选区。向上滚动会把选区推向远离玩家的方向，向下滚动会把选区拉向靠近玩家的方向，因此玩家面朝的方向决定了选区被推还是被拉的方向。选区各个面上的箭头会指示「向上滚动」所对应的方向。

按住 X、Y 或 Z 键，可以强制选区只沿单一坐标轴移动。例如，在微调选区时按住 X 键，就会强制它只沿 X 轴移动。

4.3.3　修改选区（Modifying Selections）#

你还可以通过两种方式进一步修改选区：翻转（flip）与旋转（rotate）。它们几乎能以任意方式改变选区的朝向。

要翻转选区，使用 Ctrl + F。这会根据你面朝的方向来翻转选区。选区侧面上的箭头会指示选区将被翻转的方向。

要旋转选区，使用 Ctrl + R。这会让选区在 X 轴和 Z 轴上顺时针旋转。例如，一个朝北的选区在旋转后将会朝向东方。

在拥有选区的情况下，你仍然可以用中键来扩展选区。使用左键或右键同样可以重新设置角点。

4.3.4　确认选区（Confirming Selections）#

当你对移动和修改的结果满意后，使用右键确认选区，从而放置选区中所显示的方块。

如果你对结果不满意，使用 Ctrl + Z 撤销放置。如果你拿不定主意，可以使用 Ctrl + Y 重做你的撤销。

当你对移动和修改的结果满意后，使用右键确认选区，接着使用左键完成选区。如果你想创建多份副本，就改用鼠标滚轮移动选区，而不是结束（完成）选区。

如果你对结果不满意，使用 Ctrl + Z 撤销放置。如果你拿不定主意，可以使用 Ctrl + Y 重做你的撤销。

4.5　堆叠（Stack）#

堆叠工具（Stack）允许你以一排或网格的形式复制方块与实体。

4.5.1　创建选区（Creating Selections）#

要创建选区，首先用左键选择第一个角点，然后用右键选择第二个角点。你也可以用中键来选择面而不选择角点。这让选择那些本身没有明显棱边的方块变得容易得多。

4.5.2　堆叠（Stacking）#

当你对选区满意后，滚动鼠标滚轮即可对它进行堆叠。此时会出现一个全息投影来表示你要操作的堆叠结果。同时你还会看到不同的操作控件。

使用滚轮，可以按一步为单位微调选区。向上滚动会让选区朝远离玩家的方向堆叠，向下滚动会让选区朝靠近玩家的方向堆叠，因此玩家面朝的方向决定了选区的堆叠方向。选区各个面上的箭头会指示堆叠方向。

按住 X、Y 或 Z 键，可以强制选区只沿单一坐标轴堆叠。例如，在微调选区时按住 X 键，就会强制它只沿 X 轴堆叠。

在堆叠过程中按下 中键，会把所选对象堆叠到你按下中键所指向的位置。

4.5.3　确认选区（Confirming Selections）#

当你对移动和修改的结果满意后，使用右键确认选区，从而放置选区中所显示的方块。

如果你对结果不满意，使用 Ctrl + Z 撤销放置。如果你拿不定主意，可以使用 Ctrl + Y 重做你的撤销。

4.6　涂抹/拉伸（Smear）#

涂抹/拉伸工具（Smear）会在两个点之间拉伸方块。

4.6.1　创建选区（Creating Selections）#

要创建选区，首先用左键选择第一个角点，然后用右键选择第二个角点。你也可以用中键来选择面而不选择角点。这让选择那些本身没有明显棱边的方块变得容易得多。

4.6.2　涂抹选区（Smearing Selections）#

当你对选区满意后，滚动鼠标滚轮即可对其进行涂抹/拉伸。此时会出现一个全息投影来表示你要操作的选区。同时你还会看到不同的操作控件：使用中键可以把选区涂抹到你面朝的方向。

使用滚轮，可以按一格为单位微调选区。向上滚动会把选区推向远离玩家的方向，向下滚动会把选区拉向靠近玩家的方向，因此玩家面朝的方向决定了选区被推还是被拉的方向。选区各个面上的箭头会指示「向上滚动」所对应的方向。

按住 X、Y 或 Z 键，可以强制选区只沿单一坐标轴涂抹/拉伸。例如，在微调选区时按住 X 键，就会强制它只沿 X 轴涂抹/拉伸。

4.6.3　涂抹的特性（Smearing Properties）#

起点与你的选区之间的路径中不能包含任何固体方块。位于涂抹路径上的固体方块会截断涂抹效果。

这意味着最好用三维（3D）对象来做 3D 拉伸，用二维（2D）对象来做 2D 拉伸，依此类推。这样能确保拉伸效果在你的应用场景下最为美观。

4.7　挤出（Extrude）#

挤出工具（Extrude）是一个独特的建造工具，因为它不使用选区。挤出工具只是对同一个方块的一个面进行「挤出」和「收缩」。

要挤出一个面，使用右键。要收缩一个面，使用左键。

如果你对结果不满意，使用 Ctrl + Z 撤销放置。如果你拿不定主意，可以使用 Ctrl + Y 重做你的撤销。

4.8　删除（Erase）#

删除工具（Erase）可以移除一个长方体选区，或者移除 128 个相连的同类方块。

4.8.1　创建选区（Creating Selections）#

要创建选区，首先用左键选择第一个角点，然后用右键选择第二个角点。你也可以用中键来选择面而不选择角点。这让选择那些本身没有明显棱边的方块变得容易得多。

在拥有选区的情况下，你仍然可以用中键来扩展选区。使用左键或右键同样可以重新设置角点。

4.8.2　确认选区（Confirming Selections）#

当你对选区满意后，使用键盘上的 del 或 backspace 键来移除所选区域。

如果你对结果不满意，使用 Ctrl + Z 撤销删除。如果你拿不定主意，可以使用 Ctrl + Y 重做你的撤销。

4.8.3　删除相连方块（Erase Connected）#

要移除距离最近的 128 个同类方块，把准星对准你想移除的方块并按下右键。Ctrl + Z 与 Ctrl + Y 的用法在此同样适用。

4.9　设置对称（Setup Symmetry）#

设置对称（Setup Symmetry）允许你放置并配置一个「对称节点（symmetry node）」。节点设置好之后，你就可以开始带对称地放置方块了。

4.9.1　设置对称节点（Setting The Symmetry Node）#

把准星对准你希望设置的对称点并按下右键。对称点会以一个小立方体表示。立方体的颜色代表它的状态：灰色表示对称已被禁用，黄色表示对称已启用。

对称节点可以放置在方块的面、顶点和棱边上。

4.9.2　对称修改器（Symmetry Modifiers）#

要启用对称，你需要使用翻转（flip）或旋转（rotation）修改器。

  • 要使用翻转修改器，按 Ctrl + F。例如，要在 X 轴上翻转，就面朝 X 轴方向并使用翻转修改器。三个坐标轴都适用。
  • 要使用旋转修改器，按 Ctrl + R。与翻转不同，它只能在一个轴上生效。

只要对称节点已经设置好，你在任何时候都可以使用这些按键绑定。

翻转修改器可以同时使用不止一个坐标轴，你也可以把翻转修改器和旋转修改器同时组合使用。

随时可以通过按 del 或 backspace 键来移除该节点。也可以通过移除所有修改器来临时禁用该节点。

提示提示（Tip）：如果玩家超出 256 格的范围，节点会被移除。

4.10　标记实体（Marker Entities）#

标记实体（Marker Entities） 是《我的世界》原版在 1.17 加入的一项功能。本质上，它们是几乎没有行为的实体。Axiom 利用了这一点，提供了一个「小控件（Gizmo）」来控制标记实体。

右键点击标记小控件会打开一个菜单，允许你为标记实体输入自定义 NBT。

当小控件处于激活状态时，按 Ctrl+C 会把标记数据复制到剪贴板。按 Ctrl+V 会把复制好的标记实体粘贴到世界中。

标记实体无法通过 Axiom 生成。

4.10.1　备注（Notes）#

关于标记实体的更多信息，可参阅 Minecraft Wiki 上的「Display Entities / Marker」相关词条。

4.11　颜色选择器（Colour Picker）#

颜色选择器（Colour Picker）是一个用于查找颜色相近方块、获取方块颜色，或按十六进制颜色代码（hexadecimal colour codes）查找方块的工具。

4.11.1　选项（Options）#

  • 完整方块（Full Cube，快捷键 F） 选项确保相似方块区块中只显示 1x1x1 的方块。
  • 固体（Solid，快捷键 S） 选项确保相似方块区块中只显示可碰撞（collidable）的方块。
  • 不透明（Opaque，快捷键 O） 选项确保相似方块区块中不显示透明方块。
  • 相同纹理（Same Texture，快捷键 T） 选项确保相似方块区块中只显示纹理一致（uniform）的方块。
  • 屏幕中部附近的吸管（Eye Dropper）槽位，可以将物品拖拽到上面以获取该物品的平均颜色。
  • 在右下角的文本框中可以输入一个十六进制颜色码（Hex Code），以获取颜色相近的方块。
  • 各种 RGB 与 HSB 滑块可用于微调颜色，该颜色将被用于在左侧的相似方块区块中推荐方块。
提示注意：那些被认为应当被「FSOT」选项过滤掉的属性，其方块仍可能出现在相似方块区块中，因为模组作者和 Mojang 需要以正确或合理的方式注册这些物品。

4.12　渐变助手（Gradient Helper）#

渐变助手（Gradient Helper）是一个强大的工具，可以基于两个或多个输入方块的平均颜色来创建渐变。渐变助手使用 OKLab 色彩空间，会在各个输入槽之间对块进行插值，从而构建渐变。渐变的大小与复杂度取决于物品所放置的槽位。

4.12.1　选项（Options）#

  • 完整方块（Full Cube，快捷键 F） 选项确保只使用 1x1x1 的方块来构建渐变。
  • 固体（Solid，快捷键 S） 选项确保只使用可碰撞（collidable）的方块来构建渐变。
  • 不透明（Opaque，快捷键 O） 选项确保不使用透明方块来构建渐变。
  • 相同纹理（Same Texture，快捷键 T） 选项确保只使用纹理一致（uniform）的方块来构建渐变。
  • 输出槽上的刷新（Refresh）按钮可用于切换到下一个或上一个最佳匹配。
  • 复制到快捷栏（Copy to Hotbar，书本与羽毛笔图标） 选项会把输出的渐变放入你的快捷栏，并替换掉已有物品。
  • 导出到编辑器的渐变刷（Gradient Brush）与渐变画笔（Gradient Painter） 选项会把当前渐变导出到指定工具各自的方块列表中。
提示注意：那些被认为应当被「FSOT」选项过滤掉的属性，其方块仍可能出现在渐变中，因为模组作者和 Mojang 需要以正确或合理的方式注册这些物品。

第 5 章上下文菜单与能力（Context Menu & Capabilities）

5.1　上下文菜单（Context Menu）#

上下文菜单（Context Menu）是 Builder Mode（建造模式）的一部分，提供了一系列选项，用于修改你查看世界以及与世界交互的方式。

5.1.1　Hotbar Swapper（快捷栏交换器）#

Hotbar Swapper 是原版「已保存的快捷栏（Saved Hotbars）」的增强版——原版快捷栏保存在创造模式物品栏中，并通过按键加载。Hotbar Swapper 位于上下文菜单的中心位置，且可保存的快捷栏数量无限。

  • 保存物品到 Hotbar Swapper：在上下文菜单打开时，使用鼠标滚轮选中你想保存到的那个快捷栏。
  • 随后关闭上下文菜单，用你想要的物品填满你的快捷栏。
  • 完成后，你可以滚动到下一个你想修改的快捷栏。
  • 另一种修改快捷栏的方式是：用左键点击一个物品，再用左键把它放到另一个位置。
提示注意：快捷栏不会在世界之间传递，但可以复制并重命名到你的世界中的 minecraft/config/axiom/hotbars 文件夹下。

加载已保存的快捷栏很简单：只需在上下文菜单中用鼠标滚轮选中你想使用的快捷栏，然后关闭上下文菜单，之前保存的方块和物品就会被加载到你的快捷栏中。

提示提示：在 axiom.hocon 中将 autoSwapToOtherHotbarWithItem=false 改为 true，可以让你在中键点击时自动切换到已经包含该物品的快捷栏。

5.2　Capabilities 能力#

Capabilities 会改变你与世界交互的方式。

  • Bulldozer（推土机）

  • Infinite Reach（无限触及）
  • 允许你在任意距离放置和破坏方块。

5.4　No Updates（不更新）#

No Updates 能力会把方块及其相邻方块「冻结」在当前状态，并在附近破坏或放置方块时阻止形状更新与邻接更新。

这在使用楼梯/栅栏/墙等方块的「非原版」状态时非常有用——正常情况下，在其附近破坏/放置方块会使它们恢复为原版状态。

本页附带一段约 23 秒的演示视频，展示在启用 No Updates 时，附近方块保持冻结、不发生形状或邻接更新的效果。

5.5　Force Place（强制放置）#

Force Place 能力会绕过正常的放置限制。

  • 通常需要附着在固体方块上的方块可以被放置在空中。
  • 方块可以被放置在实体内部（包括你自己）。
  • 植物类方块不再需要放置在耕地上。
  • 方块可以不受光照等级限制地放置。
  • 以及更多！
提示提示：Force Place 最好与 No Updates 配合使用，以确保非法放置的方块在被更新时不会破坏。你可能还需要用 /gamerule randomTickSpeed 0 来禁用随机刻。

5.6　Replace Mode（替换模式）#

Replace Mode 能力允许你通过右键点击把目标方块替换为手中持有的方块。这样你只需按住鼠标右键，就能轻松替换大量方块。

此外，当你替换一个方块时，新放置的方块会继承旧方块的属性。

本页附带一段约 12 秒的基础演示视频，展示 Replace Mode 的用法。

5.6.1　Type Replace（类型替换）#

Type Replace 可以通过 Alt 菜单中的 Options Toolbox 开启。开启后，你可以手持一种基础材料方块（例如云杉木板），把楼梯/台阶/墙/栅栏等替换为它们的云杉变种。

5.7　Bulldozer（推土机）#

Bulldozer 能力允许你在一个初始的「预热」阶段之后，仅通过按住鼠标左键就极快地破坏方块。这个预热阶段是为了防止意外的、大范围的破坏。

6.1　编辑器模式（Editor Mode）#

编辑器模式（Editor Mode）包含大量用于大规模世界编辑、绘制、地形改造（terraforming）与雕刻（sculpting）的工具和操作。编辑器 UI 专为此目的而设计，将常规 3D 软件的摄像机操作方式与为《我的世界》建筑量身定制的强大工具相结合。编辑器 UI 的布局可以通过「主题（Theming）」自定义，并按你的喜好对各窗口进行「停靠（docking）」。

要打开编辑器模式，请按下位于 Enter 键下方的右 Shift 键。如果你没有右 Shift 键，可以在《我的世界》的「控制（Controls）」设置菜单中，于 Axiom 分类下修改该键位。

6.1.3　用户界面元素（User Interface Elements）#

在整个编辑器模式中，这些交互式特性会出现在界面各处。以下列出所有类型及其各自的说明。

滑块（Sliders）#

滑块表现为一个细长的、可点击的方框，框内有一个「滑块抓手（Slider Grab）」。点击滑块上的任意位置都会改变框内显示的数值。该数值会影响滑块右侧所描述的选项。

滑块有上限和下限。不过，把光标悬停在滑块上并使用 Ctrl + 点击 即可绕过这些限制，从而输入任意数值。但任何输入都必须符合该滑块的数据类型。

滑块有两种类型，决定了输入的精度。「整数（integer）」滑块只允许设置或输入整数；「浮点（float）」滑块允许输入任意小数。不过，每个滑块都有其允许的小数位数上限。输入自定义数值时，如果小数位数超过预设值，输入会被四舍五入到最接近的小数位。在「整数」滑块中输入小数时同理。

下拉框（Drop-Downs）#

下拉框同样表现为一个细长的、可点击的方框。不过，下拉框右侧带有一个箭头，用以表示其下拉功能。下拉框当前选中的选项会显示在按钮部分内部，而下拉框的说明文字位于其右侧、下拉框外部。

用左键点击下拉框会打开一个包含其中全部条目的小菜单。在 Axiom 中，下拉框用于控制某个具体操作的功能。例如，大多数工具会在「工具选项（Tool Options）」中使用「形状（Shape）」下拉框，从而在同一个选项中提供多种笔刷形状。

部分下拉框支持搜索，便于在较长的下拉列表中快速检索条目。这样的下拉框可见于「生物群系画笔（Biome Painter）」的 Biome 下拉框，以及「工具预设（Tool Presets）」下拉框。要在下拉框中搜索某个条目，请打开该下拉列表并直接开始输入你想要的条目名称。

文本框（Text Boxes）#

文本框用于设置坐标，或为「标注工具（Annotation Tool）」提供文字。要辨识文本框，只需将光标悬停到「工具选项」中的某个字段上，光标会变成「文本光标（Text Cursor）」。点击文本框字段即可输入任意 ASCII 字符。

有些文本框会限制你可以输入的字符种类。例如，「修改工具（Modify Tool）」在设置为「Translate Copies」时的 Factor X 字段只允许输入整数。

基于整数的文本框还支持基础数学表达式，例如 24+6 或 73/2，会以数值形式表示该表达式的结果作为新值。可以使用此功能的一个工具是「框选（Box Select）」工具，它允许用这种方式修改 Position（位置）与 Size（尺寸）。

开关（Toggles）#

开关用于启用或禁用所描述的功能。开关看起来像一个小按钮，启用时开关内部会出现一个小勾。开关字段的右侧是该开关功能的描述文字。

开关出现在大多数「工具选项」与菜单中。

按钮（Buttons）#

按钮出现在编辑器模式的许多位置，是访问菜单与操作的关键。按钮可见于「工具栏（Toolbar）」以及「标注工具（Annotation Tool）」中。

方块图标按钮（Block Icon Buttons）

方块图标按钮与普通按钮类似，不过大多数方块图标按钮会打开「选择方块窗口（Select Block Window）」，从而可以更改按钮内的方块。方块以 2.5D 图像的形式显示在按钮之上。

这些按钮用于表示某个工具或操作将要使用的方块。它们出现在许多功能中，例如「当前方块（Active Block）」、「工具蒙版（Tool Masks）」和「方块调色板（Block Palettes）」。

将一个方块图标按钮拖放到另一个方块图标按钮上，会复制同一个方块，从而快速更换方块。在游戏窗口中用鼠标中键把方块拖入一个方块图标按钮，同样会复制该方块，只不过来源是游戏世界。

Lua 代码编辑器（Lua Code Editor）#

Lua 代码编辑器用于「蒙版脚本（Mask Scripting）」和「脚本画笔（Script Brush）」。代码编辑器左侧包含行号计数，并支持使用 Tab 键缩进。

代码编辑器使用基础的语法高亮。语法错误会导致出错的那一行被高亮标记。

6.3　Gizmo（操纵器）#

Gizmo 是一种常见的 UI 元素，用于在 3D 世界中定位对象。

（此页面附有演示图片，展示 Gizmo 在 3D 世界中的外观。）

6.3.1　Gizmo 的组成元素（Gizmo Properties）#

一个 Gizmo 可以包含以下元素：

  • 轴箭头（Axis Arrows）：这些彩色箭头对应 XYZ 坐标。红色、绿色、蓝色箭头分别允许沿 X、Y、Z 轴拖拽 Gizmo。
  • 中心节点（Center Node）：可拖拽中心节点，同时在全部 3 个轴上移动 Gizmo。拖拽时，Gizmo 会与摄像机保持相同距离。
  • 平面节点（Plane Nodes）：平面节点用于一次沿两个轴移动对象。
  • 旋转环（Rotation Rings）：三个旋转环允许你对对象执行旋转。红色、绿色、蓝色环分别允许绕 X、Y、Z 轴旋转 Gizmo。
  • 缩放节点（Scale Nodes）：缩放节点用于「展示实体（Display Entities）」。拖拽三个缩放节点之一，会分别沿 X、Y、Z 轴进行拉伸。
  • 全局 Gizmo（Global Gizmos）：当 Gizmo 设置为全局时，轴箭头、中心节点 和 旋转环 会被锁定为世界的旋转朝向。
  • 局部 Gizmo（Local Gizmos）：局部 Gizmo 是指 轴箭头、中心节点 和 旋转环 被锁定为 Gizmo 自身的旋转朝向。

导出原理图选项允许你使用剪贴板导出一份原理图。一旦剪贴板中有内容，你就可以把它导出为原理图。

将「选择（Selection）」导出为命名二进制标签（Named Binary Tag）格式，从而可以通过结构方块或 /place 命令加载它们。注意：你可以导出任意尺寸的结构，但使用结构方块加载结构时最大只能加载 32x32 个方块。

6.7.4　将选择保存为 CSV（Save Selection as CSV）#

将「选择（Selection）」导出为逗号分隔值（CSV）格式。

6.7.5　打开参考图（Open Reference Image）#

打开一个文件浏览窗口，让你选择要加载进 Axiom 的图片。打开后，你可以把图片窗口拖拽并调整大小到任意位置。

右键点击图片窗口会显示一些用于调整参考图的选项。

  • 关闭窗口（Close Window）：移除该图片。
  • 设置过滤：最近邻（Set Filtering: Nearest）：对锐利像素进行「平滑」处理，以减少块状感。
  • 设置过滤：线性（Set Filtering: Linear）：停止对像素做平滑处理，保留锐利边缘。
  • 在游戏 UI 中显示（Show In Game UI）：使图片始终显示。禁用时，在「编辑器」之外图片会被隐藏。
  • 无边框（Borderless）：移除外部边距与缩放标签页。
  • 不透明度（Opacity）：让你设置不透明度。

Select 子菜单让用户可以执行各种功能来修改「选择（Selections）」。以下选项不涉及选择区域内的方块，仅修改选择的形状本身。

6.9.1　清除（Clear）#

  • 清除当前激活的选择。

6.9.2　移动选择（Move Selection）#

  • 移动选择本身，但不移动其中的方块。

6.9.3　过滤（Filter）#

  • 将选择过滤为仅保留所提供的那一种方块或方块类型。

  • 按所提供的偏移量扩展选择表面。

  • 按所提供的偏移量收缩选择表面。

6.10.5　显示标尺（Show Ruler）#

开关「标尺（rulers）」的渲染显示。

6.10.6　显示按键（Show Key Presses）#

此选项会在屏幕右下角显示你的键盘和鼠标输入。这对于制作教程或排查问题很有用。

6.10.7　UI 缩放（UI Scale）#

此滑块范围为 0.5 到 2。它让你更改编辑器模式中所有图形元素的大小。

6.10.8　最小亮度（Min Brightness）#

Min Brightness 滑块范围为 0 到 1。它让你更改世界中未被照亮的地方看起来有多暗。取值为 1 表示所有方块都被完全照亮，其功能类似于夜视。

6.10.9　流体不透明度（Fluid Opacity）#

Fluid Opacity 滑块范围为 0 到 1。它让你更改水的透明度以改变其可见性。取值为 0 会让水变得不可见。

出于性能考虑，岩浆和模组流体不受影响。

6.10.10　方块版本（Block Version）#

Block Version 下拉框让你设置一个《我的世界》版本，从而在 Axiom 的用户界面中将与该版本不兼容的方块高亮为红色。例如，如果你想用 Axiom 为 1.8 服务器搭建结构，这个功能非常有用。

6.11　主菜单栏：Operations（操作）#

Operations 子菜单包含各种实用的「操作」，用于修改「选择（Selections）」区域内的方块。

重要：操作只影响「选择（Selections）」。

6.11.1　填充（Fill）#

默认的 Fill 操作用指定的方块填充所选的方块区域。会打开一个小「窗口」，让你通过点击方块图标来选择方块。点击后会打开「选择方块（Select Block）」窗口。下拉框让你选择该操作以何种方式填充选择。

模式说明
Fill...（填充）填充一个选择
Fill Outline...（填充轮廓）填充一个选择的所有边缘
Fill Walls...（填充墙面）填充一个选择的水平方向边缘
Fill Top...（填充顶部）填充一个选择的顶部边缘
Fill Bottom...（填充底部）填充一个选择的底部边缘

其快捷操作版本的默认键位为 Ctrl+F。

6.11.2　就近填充（Fill Nearest）#

Fill Nearest 操作不使用指定的方块来填充选择。相反，它会对选择内的每个方块，使用距离最近的、非空气的方块来填充。

6.11.3　替换（Replace）#

Replace 操作与 Fill 类似。不过，它不是填充选择中的每一个方块，而是可以把某一种指定方块替换为另一种。

其快捷操作版本的默认键位为 Ctrl+R。注意：当有「放置（Placement）」处于激活状态时，该快捷键会被覆盖。

6.11.4　按类型替换（Type Replace）#

Type Replace 操作与 Replace 类似。不过它会根据方块类型替换整一范围内的方块。可供选择的方块限定为具有多种变体的方块。注意：替换时会保留方块属性。

6.11.5　设置生物群系（Set Biome）#

Set Biome 操作将选择范围内的生物群系设置为指定的生物群系。

6.11.6　自动阴影（Autoshade）#

Autoshade 操作使用一个太阳角度（可以是玩家所在位置，也可以是一个设定值）来为你的选择添加阴影。可以为相应的明暗效果设置不同的方块。

Autoshade 窗口有许多选项来控制方块如何受光。

选项说明
Sun（太阳）启用时，使用光照来为方块阴影着色。禁用时，使用环境光遮蔽（Ambient Occlusion）为方块着色
From（来源）From 下拉框控制选择如何受光。不同的光照模式包括：Player Position（玩家位置）、Custom Positions（自定义位置） 和 Sun Angle（太阳角度）。选择 Player Position 时，光源以玩家位置为中心。使用 Custom Positions 时，你可以设置多个固定光源。按下 Add Position（添加位置）会在你当前所在位置新增一个光源。每个光源用一个黄色的「太阳」标记，其强度可以改变，以调整该光源的亮度。Sun Angle 会在一个设定角度上创建一个「太阳」光源。这类似于「聚光」光源，不过太阳光源会以同一角度影响所有对象
Ambient Occlusion（环境光遮蔽）环境光遮蔽决定方块对光源的暴露程度。方块暴露越少，着色就越暗
Global Illumination（全局光照）全局光照是光线在多个物体之间「反弹」的效果。提高此滑块会产生更多「反弹」
Dither（抖动）添加混合效果以减少贴图间生硬的过渡
Palette Options（调色板选项）Palette Options 部分用于决定着色时使用哪些方块。当 Type 下拉框设为 Automatic（自动） 时，会根据表面来选择方块。你会得到一组开关用于过滤掉不想要的方块。当 Type 下拉框设为 Custom（自定义） 时，你可以输入自己的方块。列表按从暗到亮排序，你可以用方块图标旁的滑块来影响某个具体方块的数量

你可以在 Presets（预设）部分为 Autoshade 操作保存和加载「预设（Presets）」。

要确认 Autoshade，请按下窗口底部的 Autoshade 按钮。

6.11.7　排水（Drain）#

移除选择中的所有水。此操作还会移除方块的 waterlogged（含水）属性。

6.11.8　灌水（Waterlog）#

将所有空气方块替换为水，并将所有可含水方块替换为其含水变体。

6.11.9　平滑积雪（Smoothsnow）#

在现有地形之上添加一层介于 1 到 8 层之间的雪。不会替换任何方块，因为现有地形优先。

该操作会尽可能平滑地生成积雪。

6.11.10　模拟重力（Simulate Gravity）#

Simulate Gravity 操作对所有方块模拟重力的效果，无论它们通常是否会悬空。

6.11.11　触发更新（Trigger Updates）#

Trigger Updates 操作会移除任何位置不正确的方块。

例如，选择范围内一个悬空的告示牌会被移除。

6.11.12　掏空（Hollow）#

用空气填充所选对象的内部，只留下原对象的一层外壳。

Hollow 操作还会考虑透明/非固体方块，因此包含玻璃的外表也会被正确处理。

6.11.13　填补空隙（Fill Gaps）#

Fill Gaps 与 Hollow 操作相反，会用你的当前方块填充对象内部的空腔。

同样，会考虑透明和非固体方块。

6.11.14　生成色彩场（Generate Colour Field）#

Generate Colour Field 操作会在一个选择范围内，使用「CIELAB 色彩空间」生成一个色彩场。

色彩场（色彩空间）是一种组织颜色的方式。选择 CIELAB 是因为它使用 XYZ 坐标来表示 LAB。LAB 表示色彩空间的三个分量：

L - 明度（Lightness）#

  • 明亮映射到正 X
  • 暗调映射到负 X

A - 红/绿（Red/Green）#

  • 红色映射到正 Y
  • 绿色映射到负 Y

B - 黄/蓝（Yellow/Blue）#

  • 黄色映射到正 Z
  • 蓝色映射到负 Z

色彩场中使用的所有方块都是完整、非透明的方块，以减少相互重叠。

如果两个方块足够相似，Axiom 会尝试把它们放在同一位置。不过 Axiom 会通过偏移方块来避免这种情况，直到没有重叠为止。这意味着方块很少会被排除在外。

6.11.15　分析（Analyze）#

按每种方块的数量排序，显示一个选择范围内的每种方块类型。最后一行会显示数量与分布的总计。

6.11.16　动画重建（Animated Rebuild）#

Animated Rebuild 选项可以创建建筑逐块建造的影视化效果（cinematics）。

重要：使用 Animated Rebuild 时务必小心，因为它可能会永久破坏你的结构。

以下为 Animated Rebuild 窗口中的全部设置。所有设置都指方块放置之间的延迟。

延迟设置说明
起始延迟（Start Delay）到第一个方块被放置前的等待时间（见下方注1）
最大延迟（Max Delay）决定所有延迟的最大值
空气方块延迟（Air Block Delay）在你的选择范围内放置一个空气方块所需的时间
相同方块延迟（Same Block Delay）放置相邻的同种方块（不包括空气）所需的时间
不同方块延迟（Different Block Delay）放置相邻的不同方块所需的时间
随机额外延迟（Random Extra Delay）为每个方块延迟额外加上一段随机延迟。该额外延迟对每个被放置的方块都会随机化
水平倍率（Horizontal Multiplier）对在 Y 轴上有偏移而放置的所有方块，将其延迟乘以所提供数值
垂直倍率（Vertical Multiplier）对在 X 或 Z 轴上有偏移而放置的所有方块，将其延迟乘以所提供数值

默认情况下，Animated Rebuild 操作的起始点位于选择的正中心。要改变这一位置，请在你希望重建开始的位置放置一个结构方块。你可以放置多个结构方块，从而拥有多个起始点。

按下 Do Animated Rebuild（执行动画重建）会启动动画。要在动画中途取消，按 Ctrl+Z 还原为原结构。

6.11.17　注释（Notes）#

注1：在 3.1.0 及更早版本中，一个 bug 导致 Start Delay 以游戏刻（ticks）而非秒来计量。

第 7 章编辑器窗口详解（Windows）

7.1　编辑器窗口（Windows）#

窗口（Windows）是编辑器模式（Editor Mode）的主体组成部分。窗口支持任意布局，极具灵活性且可深度自定义。

所有窗口都围绕主视图（View）构建，因为 View 是唯一无法移除的窗口。

7.1.1　打开新窗口（Opening New Windows）#

要打开一个已关闭的窗口，请使用主菜单栏（Main Menu Bar），找到 Windows 分类。在其中可以找到每个窗口的列表及其开关。

启用某个窗口时，它会以半透明状态出现在屏幕中央。这是因为该窗口处于未停靠（undocked）状态。

7.1.2　窗口布局（Window Layouts）#

窗口可以在屏幕上以多种方式布局。要调整窗口位置，只需拖动窗口最顶部区域，将其拖放到你想要的位置。

提示提示：未停靠的窗口可以通过点击窗口标题旁的三角形来最小化。

停靠（Docking）#

要停靠窗口，请拖动窗口并悬停在出现的八个蓝色形状之一上。你既可以停靠到已有窗口上，也可以新增一个位置。

要取消停靠窗口，请抓住窗口标题将其拖过屏幕。

7.1.3　其他窗口（Other Windows）#

主题（Themes）#

主题可用于通过自定义颜色进一步定制编辑器 UI。要编辑当前主题，请在主菜单栏的 Help 下点击样式编辑器（Style Editor）。主题可以通过剪贴板导入和导出。

选择方块（Select Block）#

选择方块窗口本质上就是编辑器模式下的创造模式物品栏。你可以按方块名称或方块 ID 进行搜索。

7.2　工具选项（Tool Options）#

工具选项（Tool Options）窗口用于让工具（Tools）更改其属性。工具属性对于使用编辑器模式（Editor Mode）至关重要。

该窗口包含针对每类选项的分区，以及工具预设（Tool Presets）。

7.2.1　通用选项（Common Options）#

选项说明
Shape（形状）决定笔刷的形状。
Radius（半径）决定笔刷的大小。
Mask Surface（遮罩表面）确保工具只影响与非固体方块相邻的固体方块。
Replace Solid Blocks（替换固体方块）确保工具只替换固体方块。
Extend to Ground（延伸至地面）确保最终放置结果与地面相连，方法是将每个方块向下拉伸，直到与固体方块相撞为止。

7.3　调色板（Palette）#

调色板窗口对于把方块保存成组以便日后使用非常有用。

窗口顶部显示最近使用过的 16 个方块。点击其中任意一个方块，即可将其设为你的当前方块（Active Block）。

7.3.1　创建预设（Creating Presets）#

窗口下部用于显示你已保存的调色板。在下半部分点击右键并选择 Add new category（添加新类别），会弹出一个窗口，用于为新的调色板类别命名。

为调色板命名后，会出现一个以下拉菜单形式呈现、标题为你所取名称、内含一个石头方块的条目。在下拉菜单展开状态下，右键点击该石头方块，会显示添加新方块或移除该方块的选项。

在下拉菜单收起状态下右键点击它，会显示与该类别相关的一些选项。通过它可以向类别添加内容、重命名或删除类别。

你也可以通过从最近使用（Recently Used）方块中拖放方块来向类别添加内容。

7.3.2　在其他工具中使用预设（Using Presets in Other Tools）#

像噪声画笔（Noise Painter）这类会绘制多种方块类型的工具，支持将预设拖放进去。

提示提示：把调色板拖放到某个方块或选区上，会用该调色板中的随机方块将其替换。

7.4　物品栏（Inventory）#

物品栏（Inventory）窗口显示玩家物品栏与快捷栏中当前存在的物品。它可用于拾取方块到你的当前方块（Active Block）窗口，或快速将物品拖放到编辑器模式的 UI 中。

7.5　当前方块（Active Block）#

部分工具会使用当前方块（Active Block）窗口中指定的方块，这包括大多数绘制类工具。

编辑器 UI 中的方块可以被拖放到不同位置以产生各种效果：

  • 拖入其他 UI 元素（例如工具遮罩）以快速复制该方块
  • 拖入主视口以填充目标选区（类似于 Ctrl+F）
  • 拖入主视口以将目标方块泛洪替换为拖入的方块

当前方块可以通过 pick block（拾取方块）快速设置，默认绑定为鼠标中键。

提示提示：你可以使用鼠标中键把世界中的方块复制到当前方块。

7.6　历史记录（History）#

历史记录（History）窗口提供你已对世界所做更改的总览，以及每次操作影响了多少个方块。它允许你可视化撤销与重做操作，当前所处的历史操作会以白色文字高亮显示。

在 axiom.hocon 中将 allowClickingHistoryInEditor=false 设为 true，即可直接与历史记录窗口交互。左键点击某条历史记录，会将所有操作回退到该时间点。右键点击该条目，会将摄像机朝向该次编辑的中心。

离开世界后历史记录会被删除。不过，商业许可（commercial license）允许跨多个世界永久保存历史记录。

7.7　世界属性（World Properties）#

世界属性（World Properties）窗口让你可以更改世界的某些属性和原版行为。在单人世界中可自由访问，但在多人游戏中需要获得权限，因为共享世界时这些设置可能对他人产生重大影响。下面列出可调整的各种世界属性。

7.7.1　时间（Time）#

时间（Time）子菜单让你更改世界时间相关的设置。你可以冻结世界时间、使用滑块设定特定时间，或通过按下指定的按钮使用预设时间。

7.7.2　玩家（Player）#

玩家（Player）子菜单让你调整与玩家实体相关的属性：

  • 玩家无敌（Player Invulnerability）：切换「无敌指令」（Invulnerability Command）。
  • 踩踏耕地（Trample Farmland）：禁用此属性可防止耕地被踩踏。
  • 生物生成（Mob Spawning）：此属性对应原版的 doMobSpawning 游戏规则。

7.7.3　方块（Blocks）#

方块（Blocks）子菜单让你调整世界中与方块相关的属性：

  • 方块掉落（Block Drops）：禁用此属性会阻止所有方块掉落物，包括破坏箱子等物品栏方块时产生的物品。
  • 方块重力（Block Gravity）：禁用此属性会阻止受重力影响的方块（如沙子和沙砾）下落。
  • 火焰蔓延（Fire Tick）：此属性对应原版的 doFireTick 游戏规则。
  • 随机刻速度（Random Tick Speed）：是一个滑块，对应原版的 randomTickSpeed 游戏规则。将其设为 0 会禁用随机刻。

7.8　剪贴板（Clipboard）#

可以使用 Ctrl+C 将选区（Selection）复制到剪贴板。

右键点击剪贴板图标并选择相应选项，可以清空、旋转和翻转剪贴板内容。

左键点击「Empty（空）」剪贴板图标会打开蓝图浏览器（Blueprint Browser）。

7.8.1　使用剪贴板（Using the clipboard）#

当剪贴板中有内容时，你可以借助鼠标光标的位置，按下 Ctrl+V 将其粘贴回世界中的目标位置。这会启动一次放置（Placement）。

在放置已启动且操纵器（Gizmo）可见期间，你的主视图窗口上会出现一些选项（options），让你在正式放置前编辑本次放置。

要确认放置，请按下 Ctrl+V 或 Enter 键。

提示提示：你可以在按键绑定菜单（Keybinds Menu）中将「剪切（Cut）」功能设置为保存到剪贴板。

7.9　目标信息（Target Info）#

目标信息（Target Info）窗口显示编辑器 UI 中鼠标所指方块的信息。

该窗口包含：

  • 方块名称。
  • 该位置所处的生物群系。
  • 该方块在世界中的坐标。
  • 从你的摄像机到该位置的距离。

7.10　文本标注（Text Annotations）#

文本标注（Text Annotations）窗口可通过标注工具（Annotation Tool）的「View All Text Annotations（查看全部文本标注）」按钮访问。该窗口以带索引的列表显示世界中的所有文本标注。借助它，你可以从世界任何地方传送至、更新和移除文本标注。

文本字段（Text Field）显示该文本标注当前的内容。点击并写入内容会更改该标注所显示的文本。

传送（Teleport (X,Y,Z)）按钮显示该文本标注的位置，点击它会把玩家传送到该位置。

移除（Remove）按钮会删除该文本标注。

请注意，文本标注的颜色、不透明度或其他格式不会在此窗口中显示。

7.12　蓝图（Blueprints）#

蓝图（Blueprints）是一套用于保存和加载预制资产的系统。它们与结构文件（schematic）类似，但采用了不同的结构，针对搜索与查看做了优化。

7.12.1　创建蓝图（Creating a Blueprint）#

创建蓝图（Blueprint）的方法是：让剪贴板中有内容，然后按下 Ctrl+P。这会打开创建蓝图（Create Blueprint）菜单。在这里你可以做几件事：为蓝图命名，添加作者、标签，并旋转蓝图以生成缩略图，方便日后轻松辨认。

作者、标签和名称都是你日后轻松查找蓝图的方式。例如，搜索标签 tree 或 structure，就能找到所有包含该标签的蓝图。Axiom 自带几十个默认标签，以覆盖尽可能广泛的蓝图类型；如果这些不能完全满足你的需要，你随时可以通过点击 +、输入名称并在「Add Tag（添加标签）」菜单中点击「Create Tag（创建标签）」按钮来创建自己的标签。

保存蓝图时，会打开一个属于你操作系统的原生文件系统对话框。它会让你确认想要为蓝图起的名称，并允许你将其作为 .bp 文件保存到本地电脑上。这意味着你可以轻松地在一个世界或服务器中创建蓝图，然后在另一个世界中使用它们，而无需处理繁琐的导入/导出 schema。文件本身存储在 .minecraft 文件夹下的 .minecraft/config/axiom/blueprints 中，该路径可在 axiom.hocon 配置文件中更改。

提示提示：使用 Tab 键可以更快地浏览创建蓝图窗口。

7.12.2　分享蓝图（Sharing Blueprints）#

蓝图文件本身可以发送给其他人，只要对方将文件放到指定位置，他们也就能在 Axiom 中使用。蓝图文件夹还支持嵌套目录，这意味着你可以例如把所有树木放在蓝图文件夹下的一个文件夹里。

7.12.3　蓝图浏览器（Blueprint Browser）#

有了蓝图后，你可以在蓝图浏览器（Blueprint Browser）中查看它们。

你可以通过点击剪贴板窗口（Clipboard window）中的大按钮，或使用「主菜单栏 > Windows > Blueprint Browser」来打开蓝图浏览器。

你将能看到所有蓝图的缩略图，也可以进行搜索或按标签筛选。启用「Search inside Folders（在文件夹内搜索）」会对蓝图浏览器进行递归搜索。点击某个蓝图会「打开」它并将其加载到你的剪贴板（Clipboard）中。

提示提示：你可以通过搜索框旁的相应按钮返回和刷新。

7.12.4　多人游戏（Multiplayer）#

在多人游戏中，蓝图可以保存到服务器并从服务器下载，而不是保存到你的设备上。这意味着服务器上的所有人都可以使用你保存的蓝图。

7.13　工具遮罩（Tool Masks）#

工具遮罩（Tool Masks）让用户能够为工具设置规则，仅当满足特定条件时才施加其效果。借助布尔逻辑，工具遮罩允许用户在各种场景下指定方块条件，例如只影响上方为空气的方块，或下方为特定类型方块的方块。这些规则配置被称为「规则块（Rule Blocks）」，可以通过拖放界面在工具菜单中轻松排列，提供了一种比脚本语言更友好的替代方案。你的遮罩配置会以字符串形式显示在菜单顶部，便于复制、分享和保存。遮罩逻辑会产生一个布尔输出，表示 true 或 false。

条件分为两大类：逻辑（Logic）与遮罩（Masks）。

7.13.1　逻辑条件（Logic conditions）#

将这些逻辑条件组合起来，可以在遮罩中表达极为丰富的规则，使你能够选中几乎所有满足特定条件的方块。

逻辑说明
OR（或）OR 条件使该块内的任意规则生效。例如，当要遮罩多个方块时，选择匹配 grass_block OR stone 的方块。
AND（与）AND 条件要求该块内的所有规则都成立。例如，你想要选中上方是空气且下方是泥土的方块。不过，相互冲突的规则无法在同一个 ANY 块中生效，意味着你不能同时拥有两个 block = 遮罩或两个 above = 遮罩。但你可以在其中嵌套另一个 AND 块。
NOT（非）NOT 条件反转规则结果，仅当原始条件不满足时才为真。例如，在 NOT 块中设置规则 above = air，会选中所有上方不是空气的方块。
OFFSET（偏移）OFFSET 条件允许输入坐标，以对相对于当前方块的附近方块应用遮罩。例如，使用 offset(0,-1,0){ surface } 会遮罩位于表面上方 1 格处的方块。

7.13.2　遮罩（Masks）#

遮罩是取决于目标自身状态或周围方块状态的条件。

遮罩说明
Block（方块）当目标匹配指定的方块或方块状态时，Block 遮罩返回真。
Above（上方）当目标方块正上方的方块匹配指定的方块或方块状态时，Above 条件为真。
Below（下方）当目标方块正下方的方块匹配指定的方块或方块状态时，Below 条件为真。
Near（附近）当目标周围设定半径内的任意方块匹配指定的方块或方块状态时，Near 条件为真。
Neighbour（相邻六面）当与目标直接相邻的六个方块（上、下、北、南、东、西）中的任意一个匹配指定的方块或方块状态时，Neighbor 条件返回真，使遮罩可以检查目标方块的紧邻区域。
Adjacent（相邻四面）当任意一个水平方向相接触的方块匹配指定的方块或方块状态时，Adjacent 条件返回真。
Y（Y 坐标）当目标满足与方块 Y 坐标层高相关的给定条件时，Y 遮罩返回真。Y 遮罩有多种条件，可通过点击 = 号进行修改。
Angle（角度）Angle 遮罩使用两个输入。Angle 输入用于遮罩特定角度，Range 输入则是从 Angle 输入出发所涵盖的角度数量。例如，角度为 90、范围为 10，就会覆盖从 80 到 100 的所有角度。
In Selection（在选区内）当目标方块位于用户定义的选区内时，In Selection 条件返回真。
Can See Sky（能看到天空）当目标方块可直接接触天空时，Can See Sky 条件返回真。
Surface（表面）当方块与空气或液体相邻时，Surface 遮罩返回真。

7.13.3　遮罩脚本（Mask Scripting）#

遮罩脚本使用与脚本画笔（Script Brush）相同的格式。遮罩脚本允许用户使用 Lua 输入自定义脚本。不过仍然要求返回一个布尔值。

第 8 章选择、绘制与实用工具

8.1　工具（Tools）#

Axiom 提供了一套丰富的工具，用于实时、精确地操控你的《我的世界》（Minecraft）世界。这些工具可直接在「Tool（工具）」窗口的顶层找到。此外，「Tool Options（工具选项）」窗口提供了进一步的配置可能。每个工具都有其独特的设置，能极大地改变其功能与影响。我们鼓励你去探索和尝试，因为这可能带来意想不到但有趣或有用的应用方式。

提示注意：按住 Ctrl 点击滑块，可以手动输入超出默认参数上限的数值。请谨慎使用此功能。

8.1.1　笔刷（Brushes）#

大多数用于操控世界的工具都使用一种称为「笔刷（brushes）」的格式。笔刷让用户能够以预定义的形状在世界中点击并拖动，从而收集要纳入笔刷路径的方块。你可以在下拉菜单中选择笔刷的形状。默认形状是球体。

可选形状：球体（sphere）、立方体（cube）、八面体（octahedron）。

8.1.2　目标方块（Target Blocks）#

目标方块（Target Block）可以是笔刷笔迹所绘制半径内的任意方块。目标方块用于「遮罩（Masks）」和「脚本画笔（Script Brush）」。

本质上，目标方块就是笔刷笔迹中当前正在处理的方块。遮罩和其他操作可以影响每个目标方块的处理过程。

8.2　选择工具（Selection Tools）#

本节介绍选择工具及其选项。有一个对所有选择工具都通用的选项，其概念称为布尔运算（boolean operations）。默认选项是「add（添加）」。

布尔运算说明
Add（添加）将所选区域添加到当前选区
Subtract（减去）从当前选区中减去所选区域
Replace（替换）用所选区域替换当前选区
Intersect（交集）仅选择与当前选区重叠的区域
提示注意：在非常大的尺度下，非长方体选区由于需要跟踪整个区域的复杂度，性能会下降。如果你需要对非常大的区域执行操作，建议使用长方体选区并涵盖整个建筑。

8.3　魔法选择（Magic Select）#

魔法选择（Magic Select） 是一个强大的选择工具，如果使用得当，能极大提升建造流程。只需单击一个方块类型，魔法选择工具就会迅速选中所有相邻的同类型方块，从而简化选择过程。

本工具包含以下选项：

Compare（比较） 选项模式让你选择可以与原始方块相邻选中的方块类型。默认模式为「Block」。

比较类型说明
Block（方块）所有相同类型的方块，包括所有方块状态（blockstates）。
BlockState（方块状态）与目标方块具有完全相同方块状态的所有方块。
Solid（固体）任何你无法穿过的方块。例如石头、玻璃板等。不包括花、水等。
Any（任意）所有直接相邻的方块，包括非固体方块，但不包括空气。这会让它一碰到空气就「停止」。

Limit（数量上限） 选项是一个滑块，可配置总共应选中多少方块。魔法选择算法的工作原理是从中心方块向外扩展，形成一个八面体。增大上限只是让你能选中更多方块。默认上限设置为 100,000 个方块，但可以设置为任意上限。

Range（范围） 选项是一个滑块，让你设置算法搜索任何相邻方块时的搜索距离。这让工具能够「跨越间隙」连接两个方块。范围即它在切断之前能搜索多远。例如，一棵茂密的树，其树叶和原木之间可能夹着一两格空气。这让你能选中树上所有的树叶，而不管两根带树叶的树枝之间是否存在空气方块。

Surface Only（仅表面） 是一个开关，使工具只选中选区表面的方块，或者等价地说，只选中与空气或「外部」相邻的所有方块。

Up（向上） 是一个开关，使工具只选中位于光标上方的方块，包括它所悬停的那个方块。

Down（向下） 是一个开关，使工具只选中位于光标下方的方块，包括它所悬停的那个方块。

Horizontal（水平） 是一个开关，允许工具选中水平相邻的方块。

Corners（拐角） 是一个开关，需要启用「Horizontal」才能使用。它将允许工具选中那些彼此并不直接接触、但处于「Range」所指定范围内的方块。

提示提示：你可以拖动点击跨越多个方块类型，以选中不止一种方块类型。

8.4　框选（Box Select）#

框选（Box Select） 工具允许你创建长方体（cuboid）选区。开始时，在两个点之间点击并拖动。可以通过重新摆放 3 个 Gizmo（操控手柄）来进一步调整选区。

如果你想改为在两个已知坐标之间进行选择，可以将这些坐标输入到工具选项中。

通过切换到 Pos1 & Pos2 模式，你还可以使用 Set 按钮按玩家位置来设置坐标。

与其他任何选择工具不同，框选有一个按钮可以取消确认选区，从而可以重新调整已确认的选区。

8.5　手绘选择（Freehand Select）#

手绘选择（Freehand Select） 工具允许你通过一次笔刷笔迹选择球体、长方体或八面体。它比较基础，但对于选择建筑中那些用其他方式可能难以选中的奇特部分，它能提供帮助。

8.6　套索选择（Lasso Select）#

套索选择（Lasso Select）非常独特，它允许用户在屏幕上绘制一个形状来确定选区。

要绘制选区，使用右键点击并画出环状形状。松开右键后，所绘轮廓将被投射到你视野内的方块上。你可以通过调整 Depth（深度） 滑块来设置选区的深度。

启用「Include Non-Solid（包含非固体）」将允许选区包含矮草之类的方块。

8.7　实用工具（Utility Tools）#

8.8　标尺工具（Ruler Tool）#

标尺（Ruler） 工具用于测量世界中两个或多个点之间的距离。你可以通过右键点击向世界添加点。一旦你选择了两个或更多点，最近的点与其前一个点之间会出现一条线。这条线的中央会显示四舍五入后的欧几里得距离（Euclidean distance），即直线距离。你可以根据需要继续添加更多点，或通过 Gizmo（操控手柄）移动它们。

当你在工具选项中查看时，你会看到关于这些点的更多信息。所显示的内容取决于你选择了两个还是更多点。

你会看到以下信息：

  • Total Length (Euclidean)（总长度（欧几里得））：从第一个点到最后一个点的直线距离，就像鸟直接飞过去一样，不考虑中间的方块。
  • Total Length (Manhattan)（总长度（曼哈顿））：水平、竖直和深度距离的总和。用《我的世界》的说法，就像玩家旅行那样：一次向上、向下、向左、向右、向前或向后移动一个方块。
  • Minimum（最小值）：点序列中最早那个点的坐标。
  • Maximum（最大值）：点序列中最晚那个点的坐标。
  • Bounding Size（包围尺寸）：围绕所有点绘制所需的盒子尺寸。
  • Yaw（偏航角，仅在有两个点时可见）：两点之间连线的偏航角。
  • Pitch（俯仰角，仅在有两个点时可见）：两点之间连线的俯仰角。

「Mode（模式）」下拉窗口中的 Circle（圆） 选项可用于将圆可视化。两点之间的距离将决定圆的半径。

Select Center（选择中心） 选项将在线的中心创建一个选区。

Split（分割） 选项可用于细分标尺线。

提示提示：标尺测量结果即使在编辑器之外也始终可见，所以用完后务必将其移除。

8.12　噪声画笔（Noise Painter）#

噪声画笔（Noise Painter） 是一个非常多才多艺的绘制工具，它让用户能够使用程序化噪声（procedural noises）在世界中进行绘制。可供挑选和配置的噪声种类繁多，每种都有独特的选项和图案，适用于不同场景。

第一个独特的选项是「3D」设置的开关，它允许噪声在 3D 中计算，从而可以绘制到表面的侧面，而不只是顶部。

接下来是 scale（缩放）选项，它用于调整噪声相对于方块网格的大小。更大的缩放意味着噪声图案会散布在更大范围的方块上。

最后，Anisotropic（各向异性）选项允许分别控制每个轴上的缩放，从而产生拉伸效果。

与所有绘制工具一样，默认情况下噪声画笔只影响固体方块。要让它同时影响空气，你需要使用工具遮罩（tool masks）。

8.12.1　噪声（Noises）#

不同噪声之间有一些共享设置。这些噪声的通用选项列于下方，各噪声的特定设置将在各自章节中描述。

  • Octaves（倍频）：此设置决定所使用的噪声层数。更多倍频会带来更多细节与复杂度，但计算开销也更高。只有当你的噪声使用超过一个倍频时，才能配置 Lacunarity 和 Gain。
  • Lacunarity（空隙度）：这会影响每个倍频的「频率」。更高的值会提高频率，使噪声图案中出现更小的特征。
  • Gain（增益）：这控制每个倍频的振幅。更高的值会增加每个后续倍频的影响力。更低的值会让倍频效果更加微妙。
  • Seed（种子）：种子值用于初始化噪声生成算法，提供一个起点。不同的种子会产生不同的噪声图案，但相同的种子总是产生相同的图案。当你想要延续一个图案而不是开始一个新图案时，保持相同的种子会很有用。
  • Jitter（抖动）：此值通过限制种子点偏离其起始网格排布的程度，来控制元胞噪声（cellular noise）看起来的均匀程度。值为 0.0 会返回完全均匀的网格图案，1.0 返回均匀度最低的图案。仅适用于元胞噪声类型 Voronoi Edges、Worley 和 Metaballs。

Simplex（单纯形噪声）#

Simplex 噪声生成一种平滑、连续的图案，可视化时往往类似起伏的山丘或波浪地形。

Simplex 噪声是 Perlin 噪声的改进版本。

Worley（沃利噪声）#

Worley 噪声也称为元胞噪声（cellular noise），它创建的图案看起来像不规则的细胞或 Voronoi 图，每个「细胞」都有一个明显的强度点，并向其边界逐渐淡出。

  • W1：这是最近的 Voronoi 点距离的权重。
  • W2：这是第二近的 Voronoi 点距离的权重。
  • W3：这是第三近的 Voronoi 点距离的权重。

W1、W2、W3 值之间的相互作用会显著影响 Worley 噪声的结果。例如，如果 W1 高而 W2、W3 低，图案将具有清晰定义的、不规则的细胞。但如果 W1、W2、W3 都很高，图案会更复杂、更相互连通，因为它受到多个邻近点的影响。

Voronoi Edges（Voronoi 边缘）#

这种噪声专门强调 Voronoi 图中形成的细胞之间的边缘或边界，产生一张相互连通的线条网格，或呈现「龟裂」的外观。这对于制作裂缝、石砖等很有用。

Metaball（元球噪声）#

Metaball 噪声创建的图案看起来像相互重叠的斑块或球体，这些「斑块」之间有平滑的过渡。类似于熔岩灯中斑块的图案。

  • Range（范围）：调整每个点周围影响噪声的半径。更大的范围会产生更大、更分散的斑块，更接近前述熔岩灯斑块的图案。

White Noise（白噪声）#

白噪声生成完全没有可辨结构的随机图案，看起来像老式电视屏幕上的雪花点。

Splatter（泼溅）#

遵循与 Simplex 类似的图案，但为分布添加了随机偏移。

8.12.2　方块（Blocks）#

噪声配置下方的区域允许你指定绘制所用的方块，以及它们在噪声图案中的分布。你可以通过在 0 到 1 之间设置阈值，或为每个方块指定 0 到 100% 的百分比，来调整方块分布。当你为 Worley 这类复杂噪声调整参数时，阈值设置尤其有用。

点击「+」号可添加一个新方块。点击已有方块可以让你选择并向噪声图案中添加不同的方块。你也可以将调色板（palettes）和当前方块拖放到方块区域。

要修改方块的属性，右键点击方块图标会弹出一个菜单，让你切换并设置不同属性。

当使用了一个或多个具有多种属性的方块时，方块列表底部会出现一个 Copy Properties 按钮。它会用相同的方块状态覆盖已有的方块，同时保留噪声图案。

8.12.3　条件性选项（Conditional Options）#

Copy Properties（复制属性） 选项会在所选方块之一具有方块属性时出现。启用此选项进行绘制时，会自动匹配你所覆盖方块的属性。

Type Replace（类型替换） 选项会在所有所选方块都具有诸如楼梯、台阶、栅栏等变体时出现。启用此选项进行绘制时，会自动替换你所覆盖方块的类型，并在此过程中保留其属性。

8.12.4　预览（Preview）#

最后，在设置下方有三个窗口，用于帮助可视化噪声图案、累积分布和概率密度：

  • Noise Preview（噪声预览）：顾名思义，它提供了当前噪声设置在映射到体素网格后的近似外观。它使用灰度表示方块的分布，白色表示主方块，随着添加更多方块颜色逐渐变暗。黑色表示没有方块。
  • Cumulative Distribution & Probability Density Visualizers（累积分布与概率密度可视化器）：当你把 Blocks 模式设置为基于阈值时，这些工具尤其有用。它们帮助说明方块将如何分布在噪声图案中。累积分布可视化器提供一个图表，显示当噪声阈值从 0 增加到 1 时不同方块的累积百分比。概率密度可视化器让你了解每个方块在给定噪声值下出现的可能性。它可以帮助你理解并微调噪声图案中方块的平衡。

8.13　生物群系画笔（Biome Painter）#

生物群系画笔（Biome Painter） 与 画笔（Painter） 工具类似，区别在于它绘制的是生物群系而不是方块。Minecraft 中的生物群系由 4x4x4 的方块单元表示，并在世界高度处截止。虽然生物群系以单元形式存储，但在渲染时会被改变，使其形状不规则。

你可以从下拉框中选择任何生物群系，包括发送到客户端的模组生物群系。生物群系按字母顺序排序。

Fill Vertically（垂直填充）选项启用时会填充整个世界高度的跨度，让用户能快速绘制整列。

Visualize Biome（可视化生物群系）开关默认开启，显示生物群系在 4x4x4 网格中的「真实」位置。

提示提示：你可以在下拉框中开始输入以搜索生物群系。对预设下拉菜单同样适用。

-- 获取目标方块状态 ID 并检查它是否与草方块状态 ID 匹配

end

8.14.4　findClosestBlockToRGB(`RGB triplet (integer)`, `flags bitarray (integer)`, `index`)#

返回与给定 RGB 值最接近的方块的方块状态 ID。RGB 值表示为一个 8 位 RGB 三元组，其中第一、第二、第三个八位对分别代表该方块的 r、g、b 颜色值。你可以用 flags 过滤方块查找列表，类似于取色器和渐变工具的工作方式。所有 flag 列于下方。你可以通过指定 index 对列表中所选方块进行偏移，从而获得与给定颜色第 i 接近的匹配。

Flags 格式：

代码
加 1 以仅使用固体方块
加 2 以仅使用不透明方块
加 4 以仅使用 1x1x1 方块
加 8 以仅使用六面完整的方块
加 16 以排除矿石
加 32 以排除带釉陶瓦
加 64 以排除方块实体

代码示例：

代码
function rgbToTriplet(r, g, b) return r*(256^2) + g*256 + b
end -- 放置游戏中毫无疑问最蓝的方块

color = rgbToTriplet(0, 0, 255)
block = findClosestBlockToRGB(color, 0, 1)
return block

getBlockRGB(`Blockstate ID`)#

返回给定方块的 RGB 三元组，表示为一个数字，其中第一、第二、第三个八位对分别代表该方块的 r、g、b 颜色值。你可以像示例中那样用取模运算符从三元组中提取单独的 RGB 值。对于空气这类方块，此函数会返回 nil 值，这可能会在你的脚本中引发错误，因此需要对这种情况进行处理。

代码示例：

代码
-- 此函数将合并的 RGB 三元组值转换为单独的 rgb 值，并存入一个表
function tripletToRGB(triplet)
local r = math.floor( triplet/(256^2) )
local g = math.floor( (triplet%(256^2))/256 )
local b = triplet%256 return {r, g, b}
end function vecScale(vec, scale)
local x = vec[1]*scale
local y = vec[2]*scale
local z = vec[3]*scale
return{x, y, z}
end function vecFloor(vec)
local x = math.floor(vec[1])
local y = math.floor(vec[2])
local z = math.floor(vec[3])
return{x, y, z}
end function rgbToTriplet(rgb_vec) -- 如果进行向量运算，你需要将 rgb 值四舍五入为整数以避免失真，我用 floor 函数来做到这一点
truncated_vector = vecFloor(rgb_vec)
return truncated_vector[1]*(256^2) + truncated_vector[2]*256 +truncated_vector[3]
end -- 将方块变暗 10%

multiply = 0.90
block = getBlock(x,y,z)

color_triplet = getBlockRGB(block)
if color_triplet then -- 处理空气或洞穴空气这类没有颜色的方块返回的 NIL 值
color_vector = tripletToRGB(color_triplet)
scaled_color_vector = vecScale(color_vector, 0.90)
darkened_triplet = rgbToTriplet(scaled_color_vector)
darkened_block = findClosestBlockToRGB(darkened_triplet)
return darkened_block
end

8.15　渐变画笔（Gradient Painter）#

渐变画笔（Gradient Painter） 工具允许你使用多个方块来绘制渐变。

使用方法：点击 pos1，你会看到出现一条线。点击并拖动以从 pos2 开始绘制。

Mask Surface（遮罩表面） 选项允许只绘制与非固体方块相邻的方块。

与所有绘制工具一样，默认情况下渐变画笔只影响固体方块。要让它同时影响空气，你需要使用工具遮罩（tool masks）。

8.15.1　平面渐变与球形渐变（Planar vs Spherical Gradients）#

你可以选择渐变的类型为球形（spherical）或平面（planar）。

如本页示意图所示，对于「Plane（平面）」选项，渐变从 pos1 到 pos2 沿一个方向进行。对于「Sphere（球形）」选项，渐变从 pos1 向 pos2 辐射，其中 pos2 是半径，pos1 是中心（即起始点）。

8.15.2　插值（Interpolation）#

你可以选择要使用的插值类型：Nearest（最近邻）、Linear（线性）和 Bezier（贝塞尔）。

本页示意图从上到下依次展示：Nearest、Linear、Bezier。

你可以查阅相关曲线以了解其具体计算方式，但本质上，Nearest 会在每种方块类型之间给出硬边界。Linear 顾名思义给出平滑过渡，而 Bezier 在中心处变化更快，并在两端进行缓入/缓出。在较大范围的渐变中，效果更为明显。

8.15.3　锁定（Locking）#

你可以在不锁定、仅锁定 pos1、以及同时锁定 pos1 和 pos2 之间选择。

不锁定会让渐变的起点和终点在每次笔迹中都发生变化。

仅锁定 pos1 会让渐变的起点在你松开鼠标按键后仍保持固定。但 pos2 仍不固定，因此渐变的长度可以自由改变。

同时锁定 pos1 和 pos2 会让渐变的起点和终点都保持固定，你可以使用多次笔迹以相同的效果覆盖同一区域。

要解锁这些点，将锁定选项选为「none」。

8.15.4　边缘钳制（Clamp to edge）#

如果启用此选项，渐变的应用方式将使其不会延伸到 pos2 之外。

8.15.5　条件性选项（Conditional Options）#

Copy Properties（复制属性） 选项会在所选方块之一具有方块属性时出现。启用此选项进行绘制时，会自动匹配你所覆盖方块的属性。

Type Replace（类型替换） 选项会在所有所选方块都具有诸如楼梯、台阶、栅栏等变体时出现。启用此选项进行绘制时，会自动替换你所覆盖方块的类型，并在此过程中保留其属性。

第 9 章塑造、流体、高度图与操纵工具

9.1　绘制工具（Drawing Tools）#

绘制工具（Drawing Tools）用于对世界进行雕刻，以类似其他 3D 软件中雕刻工具的方式添加或移除方块。每一种工具都使用各自独特的放置算法，从而产生不同的效果。Axiom 提供了一整套此类工具，每种工具都配备了专门的工具选项（Tool Options），用于精确地编辑方块。

9.2　自由绘制（Freehand Draw）#

自由绘制（Freehand Draw）工具是最基础的绘制工具，它使用活动方块（Active Block）来绘制。在工具选项（Tool Options）中，你可以设置笔刷的半径（radius）与形状（shape）。

9.3　塑性绘制（Sculpt Draw）#

塑性绘制（Sculpt Draw）工具是一款强大的雕刻工具，用于改变地形与有机体（organics）的形状。它利用表面所朝向的方向（即表面法线，surface normal）来决定形状的峰值应当出现在哪里。塑性绘制工具并不使用活动方块，而是从表面上“拉出”已有的方块。工具提供了多种设置，用于微调其雕刻行为：

选项取值范围 / 形式说明
半径（Radius）笔刷半径（越大形状越偏球形/椭球形，越小越接近抛物线形）与其他笔刷工具不同，塑性绘制工具中的半径不仅影响尺寸，还会影响所雕刻形体的形状。较大的半径会产生更接近球形或椭球形的形体，而较小的半径会创造出抛物线形的形体。
强度（Strength）指数滑块，0 ~ 5，可越界覆盖以设置更高数值决定所雕刻形体的强度。由于该工具基于表面法线的处理方式，不同的强度可以产生多种多样的结果，因此它非常适合创造悬垂（overhangs）、尖刺状构造，或能与现有结构无缝融合的自然侵蚀纹理。
反转（Invert）开关在向表面添加与从表面减去之间切换，可用于雕刻出侵蚀路径（erosion paths），或削去有机体结构以创造自然的笔触。
遮罩 Y 轴（Mask Y）开关启用后，工具只会沿 Y 轴方向添加质量。这会产生更渐进的改变，而非突兀的凸起，非常适合以自然的方式塑造结构物的顶面。
去噪（Denoise）开关对塑性绘制工具所绘制的形状应用去噪算法以使其平滑。通常建议保持开启，以增强工具的自然观感；但如果你希望获得更粗糙、更多岩石感的表面，则可以关闭该选项。

9.3.1　名词说明：表面法线（Surface Normal）#

表面法线是几何学中的一个概念。简单来说，它就是某个特定表面所朝向的方向。例如，在现实世界中如果你站在平地上，表面法线就是竖直向上的；如果你站在斜坡上，表面法线就会以某个角度斜着指向外侧。

9.4　岩石（Rock）#

岩石（Rock）工具是一款基于噪声（noise）的雕刻工具，适合制作岩石状的地形与形状，既可用于制作单块的岩石与巨石（boulders），也可用于让表面看起来更具岩石感、更粗糙。它使用若干参数来改变岩石的总体生成方式，以及岩石与所放置表面之间的关系。它使用活动方块来确定方块调色板（palette）。工具提供了多种设置，用于微调其雕刻行为：

9.4.1　噪声设置（Noise Settings）#

噪声设置让用户配置雕刻工具生成的岩石应当有多么随机、多么粗糙。其中有若干可调设置，用于改变噪声的行为。

选项取值范围 / 形式说明
噪声半径（Noise Radius）数值（越大影响范围越广）决定噪声所引发改动的“尺度”。较大的噪声半径意味着更广的影响区域，会影响到更多方块，从而形成更大、更团块状、通常也更加圆润平滑（因改动分布更广）的构造。反之，较小的噪声半径影响到的方块更少，会产生更精细、更参差不齐的改动，并受体素网格（voxel grid）尺寸的限制。
噪声强度（Noisiness）滑块（越高越随机、越团块化；越低越平滑、越接近球形）影响所雕刻方块的“噪声化”或随机程度。较高的噪声强度会产生更随机、更团块化的岩石；较低的噪声强度会产生更平滑、更接近球形的岩石。它与噪声半径及其他因素共同作用，影响岩石最终外观的粗糙程度。
噪声场种子（Noise Field Seed）整数种子值（默认每次笔触随机）允许你输入一个种子，以便延续先前使用过的图案，或在调整参数之后复现之前的图案。默认情况下每次笔触都会随机化。

9.4.2　平滑设置（Smoothing Settings）#

平滑设置影响由上述设置生成出来的岩石会被平滑到什么程度，目的是创造出更连贯、更统一的岩石形状，而不是一堆漂浮的团块。

选项取值范围 / 形式说明
平滑标准差（Smoothing Standard Deviation）默认 0 ~ 5，可越界扩展设置施加于该工具的高斯模糊（Gaussian blur）的强度。0 等同于不做任何平滑；2（标准值）相当于约 4 个方块范围的平滑；5 则非常平滑，范围约为 10 个方块。
融合强度（Meld Strength）默认 0 ~ 3，可越界扩展用于决定岩石应当与世界中已有方块融合（meld/blend）多强。这会使岩石在笔刷边缘附近被更多地平滑，以缓和岩石原本可能出现的参差边缘。0 表示不施加融合、直接放置在表面上；3 表示很强的融合效果。融合强度同样受平滑影响：平滑程度越高，“融合后的边缘”就会被越精细地平滑进已有方块中。

9.5　焊接（Weld）#

焊接（Weld）工具使用高斯模糊向表面添加质量，其方式类似于使用带焊丝的焊机为某个区域增补材料。它可用于填补生硬棱边之间的接缝（seams），或把现有的陆块平顺地延展（flare out）到平坦表面上，形成无缝的过渡。它使用活动方块（Active Block）来决定要放置哪些方块。该工具部分地通过笔刷设置进行配置，另有一些会以特定方式改变算法的设置。

选项取值范围 / 形式说明
平滑强度（Smoothing Strength）滑块（越高越平滑）调高可获得更平滑的焊接效果。较高的平滑设置意味着工具需要更低的阈值才能生效，因为二者会相互制约。通常，更高的平滑强度也会增大受影响区域的尺寸。
平滑阈值（Smoothing Threshold）滑块调高后工具更难影响给定区域。这样可以约束工具的作用方式，有助于创造出更自然的延展与外扩，并融入现有建筑。
替换固体方块（Replace Solid Blocks）开关切换是否允许用活动方块覆盖其他固体方块。

9.6　熔化（Melt）#

9.11　路径（Path）#

路径（path）工具具备在 3D 环境中设置多个点，并选择每个点如何用方块连接起来的能力。

所使用的方块由活动方块（Active Block）决定。

你可以在直线（line）或曲线（curve）之间选择来连接这些点。直线与曲线都各有多种变体：

  • 直线（Line）
  • Bresenham
  • DDA
  • 曲线（Curve）
  • 悬链线（Catenary）
  • Catmull-Rom 样条（Catmull-Rom Spline）
  • 贝塞尔曲线（Bezier Curve）

9.11.1　路径类型（Path Types）#

直线（Bresenham）#

一种始终只有一个方块宽、且只有在到达节点（node）时才会改变方向的直线。这是唯一一种宽度不可修改的路径类型。

直线（DDA）#

与 Bresenham 直线不同，DDA 通过“半径（Radius）”滑块获得可修改的宽度，从而可以形成圆润的路径线条。

悬链线（Catenary）#

这种路径类型会创造悬挂绳索或彩旗（bunting）的效果。对于每一个点，路径都会以“下垂”的方式走向下一个点。你可以通过增大“松弛（Slack）”滑块来增加下垂的幅度。

你还可以通过启用“反转（Inverted）”按钮来反转下垂的方向。

Catmull-Rom 样条（Catmull-Rom Spline）#

这种路径类型会平滑掉路径的方向，同时仍然会经过每一个节点。

贝塞尔曲线（Bezier Curve）#

贝塞尔曲线路径类型会平滑路径，但不要求经过每一个节点（起点与终点节点除外）。与 Catmull-Rom 样条不同，这里的节点是在“影响”方向，而不是“决定”方向。

9.17　斜坡（Slope）#

斜坡（Slope）工具是一款高度图工具，旨在轻松地在两点之间创建坡道或斜坡，其运行方式与其他高度图工具略有不同。要开始创建斜坡，你必须先点击一次来设定目标位置，然后可以从任意其他位置按住并拖动点击来开始在这两点之间绘制斜坡。

在首次点击时，会出现一个三角形，显示高度差、斜坡角度以及两点之间的欧几里得距离（Euclidean distance）等详细信息。当你按住右键并拖动时，会在斜坡的初始点周围显示一个网格平面，展示斜坡的精确角度，并提供最终斜坡外观的粗略预览。

在配置方面，笔刷设置允许你调整高度与半径。锐度（sharpness）功能与其他高度图工具类似，负责管理工具上方与下方各点处斜坡的曲率。

有两种模式可用：平面（Plane）与锥形（Cone）。平面模式作用于平坦表面，而锥形模式在以初始点为中心的球形区域内起作用。锥形的朝向会根据目标点位于你当前瞄准点的上方还是下方而改变。

不过，创建大型斜坡时要小心，因为它可能会造成卡顿。对于非常大的斜坡，建议一次只处理较小的区域。

9.18　操纵工具（Manipulation Tools）#

操纵工具（Manipulation tools）是一系列旨在把已有地形改变成更理想形状或形态的工具。例如，在某处造好一座山或一处悬崖之后，再用这些工具通过平滑、粗糙化、扭曲等方式来帮助改进它们的形状。每种工具对世界的影响都相当不同，常见的做法是在添加更多质量或雕刻世界的工具之间穿插使用这些工具，以及连续使用多个操纵工具，以获得最理想的结果。

9.19　平滑（Smooth）#

平滑（Smooth）工具使用高斯模糊来柔化地形。它与其他平滑工具的区别在于：其算法会在整个笔刷笔画范围内保持方块总数不变。它不会添加或移除多余的质量，而是尝试根据周围环境把方块均匀地铺展到所选区域内。这使得该笔刷更具自适应性、更精确，同时还提供了与此行为相关的可调设置。工具在由笔刷设置所定义的选区内运作，但请注意，模糊核（blurring kernel）也会考虑选区周围的环境。

选项取值范围 / 形式说明
平滑强度（Smooth Strength）默认 2控制地形平滑的程度。默认值为 2，可提供令人满意的平滑效果。较低的强度适合在保留整体形状的前提下细化噪声较多的区域；较高的强度则会更加剧烈地把方块混合与聚合在一起，以达到尽可能平滑的形状。
方块比例（Block Ratio）百分比（默认 100%）属于修改器（Modifiers）设置，与平滑行为有关。默认情况下工具为 100% 方块比例、处于“稳定（Stable）”模式，这意味着工具会保留所有方块（100%），并力求在平滑过程中保持相对不变。如果提高方块比例，就会添加更多质量，其数量相当于所选方块总数乘以该比例。例如，101% 的比例意味着多添加 1% 的方块，而 99% 的比例意味着移除 1% 的方块。对于较小的区域，这允许精确调整；而对于较大的选区，由于其质量更大，会自然地根据你的设置更多地增长或缩减。
Stable 模式模式选项（默认）保持方块总数基本不变地进行平滑。
熔化模式（Melt）模式选项使平滑偏向于移除方块。
生长模式（Grow）模式选项使平滑偏向于添加方块。
修复边缘（Fix edges）开关（默认开启）把被平滑区域的边缘与已有地形融合，避免产生生硬的对比。这使被平滑的区域能与其余地形无缝混合，防止出现参差的边缘。

（注：把模式与方块比例结合使用，可以实现对平滑过程的精确微调。）

9.20　扭曲（Distort）#

扭曲（Distort）工具使用一种名为“域扭曲（Domain Distortion）”的概念，结合 Simplex 噪声来对给定区域进行扭曲。它在实践中所做的就是让区域变得更加凹凸不平。这有助于让平坦的区域拥有更多深度与纹理，也可用于在更精细的地形上添加一些凸起与凹陷。它在由笔刷设置所定义的笔刷笔画路径内起作用。

可以进一步配置扭曲，以微调你想要如何扭曲地形。

选项取值范围 / 形式说明
尺度（Scale）数值；若不够大可以配置得更大设置用于执行域扭曲的 Simplex 噪声的尺度。
种子（Seed）种子值（可使用不同或随机种子）用不同的或随机的种子来配置扭曲。
距离（Distance）数值，可为非整数（如 2 表示平均偏离目标位置约 2 个方块）增大噪声扭曲所覆盖的范围。距离为 2 即表示平均偏离目标位置约 2 个方块的距离。由于噪声是连续的，该范围可以设置为非整数以便微调，有时会导致出现更大的凹陷或凸起。较高的距离会使其看起来更“剧烈（severe）”。
分离轴（Separate Axis）开关启用后，这些距离可以按轴分别设置。
平滑边缘（Smooth edges）开关把噪声的边缘混合进已有地形，以避免在扭曲区域之间出现参差的边缘与生硬的对比。

9.21　粗糙化（Roughen）#

粗糙化（Roughen）工具旨在让地形产生崎岖或参差不齐的边缘，本质上相当于平滑工具的反向操作。它通过“粗糙化”或让地形变得不那么平滑来起作用。它的笔刷大小可以配置，以改变受影响的区域。

它的工作方式是分析当前有多少面（方块的侧面）暴露在空气中，以及在粗糙化处理之后应当有多少面暴露在空气中。施加到地形上的粗糙化程度由“粗糙化比例（roughening ratio）”决定，它设定改动的比例。

选项取值范围说明
面数（Faces）滑块，1 ~ 4决定在粗糙化处理之后一个方块会有多少个侧面（面）暴露在空气中。如果该值设为 1，就需要有更少的面暴露，外观会更加崎岖；而如果设为 4，就需要有更少的面暴露（按原文说明），从而产生高度不规则、粗糙的外观。
粗糙化比例（Roughening Ratio）滑块决定粗糙化效果的强度或程度，也就是地形会被改变多少。较高的粗糙化比例会造成剧烈改变，使地形看起来明显更加崎岖；较低的比例则会施加更细微的粗糙化效果。

9.22　碎裂（Shatter）#

碎裂（Shatter）工具使用 Voronoi 边缘噪声来使地形碎裂或向地形添加裂纹。笔刷的大小与形状可以配置，以改变受影响的区域。

碎裂噪声可以被配置为更大的尺度，反之则会让裂纹出现在更广的范围内。宽度（Width）影响 Voronoi 边缘之间裂纹的大小，更大的宽度意味着裂纹更宽。切换活动方块（active block）会让笔刷使用活动方块，而不是用其来制造裂纹——这可以用于用材料来制造裂纹，而不是从世界中移除质量。

该噪声可以被配置为在 3D 中运作（意味着裂纹会在全部 3 个维度上延伸），也可以为每个笛卡尔坐标配置若干种 1D 形式，这会使裂纹只出现在那一个轴上。它同样可以配置种子，以使用不同或随机的种子。

9.23　挤出（Extrude）#

挤出（Extrude）工具旨在调整表面的大小，即把表面扩张或收缩。当你点击某个表面时，工具会影响整个面，使其根据所选模式收缩或扩张。它默认预设了 100,000 的范围上限。这样做是出于性能考虑，否则在大片平坦表面上可能会延伸到渲染距离之外。

该工具还包含一种“方块比较（block compare）”模式，其运作方式与魔法选择（magic select）工具的方块比较模式类似。该模式决定工具会影响哪些方块。可选项包括：所有方块、仅相同类型的方块、具有相同方块状态的方块、任意固体方块，或每一个方块，提供了很大的自定义空间。

挤出工具还具备“位移（displace）”功能。启用后，该功能会让厚度为一个方块的表面整体移动，而不是在其上创建副本或增补。当你想要重新摆放墙壁或天花板之类的元素而又不想改变其厚度时，这特别有用。

“数量（Count）”滑块决定每次点击放置多少层。

9.24　修改（Modify）#

修改（Modify）工具用于以多种方式操纵选区（selections）。

9.24.1　总览（Overview）#

模式说明
旋转成形（Revolve）以圆形结构拉伸选区
平移副本（Translate Copies）使用自定义偏移把选区克隆设定次数
旋转副本（Rotate Copies）介于旋转成形与平移副本之间
扭转（Twist）使用角度与轴来扭转选区

9.24.2　旋转成形（Revolve）#

当你激活选区后，会出现两条圆形线，红色表示旋转成形的内侧部分，绿色表示外侧。从光标位置指出的两条线表示旋转可以从哪些点开始。

旋转成形工具可以分别在全部三个轴上旋转，并有一个选项用于控制该工具所使用的角度大小。360 度构成一个完整循环，180 度为半圈循环。

“添加平移（Add Translation）”按钮允许你使用整数或小数来偏移旋转成形的结束位置。

9.24.3　平移副本（Translate Copies）#

与堆叠（stack）类似，平移副本允许按相对值或绝对值进行偏移。“数量（count）”控制用该偏移量制作多少个副本。

相对偏移会乘以选区的大小。

绝对偏移不会被乘，因此它们是绝对坐标。

9.24.4　旋转副本（Rotate Copies）#

如同旋转成形与平移副本的混合体，旋转副本会围绕由光标设定的一个点旋转设定数量的副本。不过，把“类型（Type）”从“等距（Equidistant）”改为“自定义角度（Custom Angle）”后，就会取消围绕点的旋转，改为依据所设定的角度偏移来旋转。

“添加平移（Add Translation）”开关启用后可以偏移末尾的副本。在 Y 轴上偏移 1 会形成螺旋形状。

9.24.5　扭转（Twist）#

扭转（Twist）功能会沿着一根轴以一定角度扭转选区。

轴（axis）控制扭转所朝向的面方向，角度（angle）决定它应当扭转多少。

11.2　白名单#

11.2.1　白名单机制概述#

Axiom 在私服（private servers）上的多人支持，主要是 Commercial License（商业授权）的一项功能。不过，如果 Axiom 仅用于非商业（NON-COMMERCIAL） 用途，可以申请白名单以获得多人访问权限，期限为 90 天；Patron（Patreon 支持者）或 Discord Server Booster（Discord 服务器助推者）则为 180 天。

  • 白名单到期后可以续期。
  • 用户也可以代他人申请，只要所提供的信息是真实的。
  • 部分服务器（例如 Builder's Refuge、The Bakery）拥有服务器白名单（server whitelist），这使得所有人都可以在不需要个人白名单的情况下使用 Axiom。
  • 注意：首次在服务器上使用 Axiom 时，会自动获得一个 30 天的多人白名单。

11.2.2　商业用途（Commercial Use）#

如果你通过使用 Axiom 完成的作品赚钱，则需要 Commercial License（商业授权）。

什么算作商业用途#

商业用途包括但不限于：

  • 自由职业建筑者（freelance builders）使用 Axiom 承接委托（commissions）。
  • 为 Marketplace 团队工作的建筑团队（build teams）。
  • 使用 Axiom 制作的建筑作品的盈利服务器（monetized servers），包括仍在开发中、尚未盈利或尚未向公众发布的服务器。
  • 任何类似的、使用 Axiom 赚钱的情形。

什么不算作商业用途#

  • 制作视频/直播内容（YouTube、Twitch、TikTok）。
  • 为 Realms 或 PlanetMinecraft 制作免费游玩（free-to-play）地图。

如果你的具体情况未在此处提及，请在官方 Axiom Discord 的 #support 频道发帖描述你的情况，并等待 Team Members 或 Staff 回复。

第 12 章实战工作流与常见问题

本章把前面各章的工具串成可落地的工作流，并汇总使用中最容易踩的坑。文中所有工具名称与参数均与官方文档一致，可直接对照执行。

12.1　工作流一：快速塑造自然地形#

目标是做出「有起伏、有材质变化、不呆板」的地形。

  1. 定大局：用「高程（Elevation）」工具推拉整体高度，或用「高度图（Heightmap）」工具绘制大尺度的高低分布。高度图工具的工作方式类似 World Machine 这类专业地形软件的分层思路。
  2. 造坡度：用「坡度（Slope）」工具控制坡面角度，避免出现直上直下的墙。
  3. 加变化：用「噪声画笔（Noise Painter）」配合 Simplex、Worley、Voronoi 边缘、元球（Metaball）等噪声类型，让表面不再均匀。
  4. 上材质：用「画笔（Painter）」替换方块材质；需要渐变过渡时用「渐变画笔（Gradient Painter）」做平面或球形渐变，并选择合适的插值（Interpolation）方式。
  5. 打磨细节：用「平滑（Smooth）」修掉噪点，用「粗糙化（Roughen）」或「扭曲（Distort）」增加自然感，用「碎裂（Shatter）」制造岩体碎裂效果。
  6. 定生态：用「生物群系画笔（Biome Painter）」刷生物群系，必要时按 Ctrl+B 打开生物群系边界渲染来核对范围。
提示实用提示：编辑器模式的任何工具都可以叠加「工具遮罩（Tool Masks）」，用逻辑条件限定作用范围（例如「只在指定方块类型上生效」「只作用于选区内部」）。这是把粗糙工具变成精细工具的关键手段。

12.2　工作流二：建筑复制、改装与批量放置#

目标是「建一次，用一百次」。

  1. 选中目标：优先用「框选（Box Select）」处理规则建筑；不规则结构用「手绘选择（Freehand Select）」「套索选择（Lasso Select）」；按方块类型或连通性选择用「魔法选择（Magic Select）」。
  2. 复制到剪贴板：Ctrl+C 复制。注意「连空气一起复制（Copy With Air）」开关——做建筑外壳时通常需要包含空气，否则内部会被原有方块填充。
  3. 调整与落位：Ctrl+V 生成放置（Placement）预览，用操纵器（Gizmo）或方向键微移（↑ ↓ ← →、Page Up、Page Down），Ctrl+R 旋转、Ctrl+F 翻转，Enter 确认。放置操作在确认前都可以自由调整，不要急着按回车。
  4. 固化为蓝图：Ctrl+P 保存蓝图，填好名称、作者与标签。标签是后续检索的关键，建议按「用途 + 风格 + 尺寸」打三个标签。
  5. 批量复用：在蓝图浏览器中按标签搜索，支持在文件夹内递归搜索。团队协作时把 .bp 文件放进 .minecraft/config/axiom/blueprints 即可共享。

12.3　工作流三：有机体与植被制作#

  1. 用「岩石（Rock）」（快捷键 H）生成岩体，用「焊接（Weld）」（快捷键 J）把碎块融合成整体。
  2. 用「熔化（Melt）」（快捷键 K）让边缘下垂，做出钟乳、藤蔓、垂坠质感的形状。
  3. 用「印章（Stamp）」把预设形状反复盖到地形上；用「路径（Path）」沿路径批量生成结构，适合做道路、河流、矿道与树列。
  4. 用「文本（Text）」「形状（Shape）」工具做标志牌与规则几何体。

12.4　工作流四：多人协作#

  • 服务器端：多人游戏中，蓝图既可以保存到本地，也可以保存到服务器并从服务器下载，这样服务器上的所有人都能使用同一套资产。是否需要在服务端也安装模组取决于服务器的具体配置，建议先在小范围测试（可用 /axiomhandshake 模拟一次「玩家加入服务器」来验证客户端与服务器的连接是否正常）。
  • 权限与合规：如果 Axiom 的使用属于商业用途（例如用于商业项目交付、商业服务器），需要先了解白名单（Whitelist）与商业授权（Commercial License）的要求，详见对应章节。
  • 常见误解：/axiomenablecheats 在多人游戏中不可用；Axiom 新增的几条游戏规则命令在 Paper 服务端上游玩时不可用。

12.5　性能与稳定性建议#

  • 大范围操作前先缩小工具半径或先用小范围试刷，确认效果后再放大。
  • 关闭暂时不需要的可视化渲染，例如「显示选区」「显示生物群系」「显示标注」「显示碰撞网格」「显示光源方块」，可明显减轻客户端的渲染压力。
  • 历史记录（History）会保留大量操作，长时间高强度编辑后如果感觉卡顿，可清理不再需要的历史。
  • 窗口布局异常时，可以删除 .minecraft/config/axiom/imgui.ini 让界面恢复默认（该文件通常不建议手动编辑）。

12.6　常见问题（FAQ）#

问：进入游戏后没看到第 10 格图标，怎么排查？

答：先在游戏内执行 /whynoaxiom，它会返回 Axiom 的状态与解决建议。若仍无法解决，请到官方 Axiom Discord 求助。常见原因是缺少 Fabric API、jar 放错目录或启动器选错了版本。

问：可以用 Forge 或 NeoForge 吗？

答：Axiom 面向 Fabric 平台发布，Modrinth 上标注不支持 Forge；同时与 OptiFine 存在冲突。建议使用 Fabric 加载器。

问：我的世界版本该选哪个 Axiom？

答：必须版本匹配。Axiom 5.2.1 提供多个构建，分别对应不同的《我的世界》版本（含 1.21.4、1.21.11 等），下载时务必选择与你游戏版本一致的那一个。

问：安装后需要把模组也装到服务端吗？

答：Axiom 在 Modrinth 上标注为客户端与服务端均为可选（optional）。实际是否需要服务端安装取决于服务器配置，官方文档未就此给出明确说明，建议先在测试服验证。

问：`Ctrl+Z` 撤销不了刚才的操作？

答：部分操作无法撤销或重做，官方文档明确提到例如在建造模式中使用替换模式（Replace Mode），以及删除展示实体（Display Entities）等。重要操作前建议先存档。

问：建造模式的 `Ctrl+C` 和编辑器模式的 `Ctrl+C` 是一回事吗？

答：不是。建造模式下 Ctrl+C 用于复制展示实体与带有精确方块属性的方块；编辑器模式下的复制是把选区内容复制进剪贴板。两组按键绑定相互独立，注意区分。

问：放置（Placement）已经生成，但我不想要了怎么办？

答：在确认（Enter）之前，放置都还只是预览状态，可以继续移动、旋转、翻转，按 Delete 或 Backspace 删除，不会改动世界。

问：`Ctrl+F`、`Ctrl+R` 在不同地方作用不一样？

答：需要区分两组绑定：编辑器模式下的「操作」类绑定 Ctrl+F 是快速填充、Ctrl+R 是快速替换；而「放置」类绑定 Ctrl+F 是翻转放置、Ctrl+R 是旋转放置。另外建造工具中的 Ctrl+F 是翻转选区、Ctrl+R 是旋转选区。建议在「按键绑定」窗口中按自己的习惯统一规划，避免记忆冲突。

问：蓝图保存在哪里？可以手动分享吗？

答：默认在 .minecraft/config/axiom/blueprints，扩展名 .bp，路径可在配置文件中修改。该目录支持嵌套子目录，可以直接把文件发给他人使用。

问：窗口被我拖乱了，或者某个窗口消失了？

答：编辑器支持窗口停靠（Docking）与主题（Themes）切换。窗口列表在打开的窗口管理里，可以重新打开被关闭的窗口；如果窗口位置错乱无法恢复，删除 imgui.ini 后重启即可恢复默认布局。

问：想要更精确的数值，但滑块拖不准？

答：按住 Ctrl 再用鼠标点击滑块，可以直接输入任意数值（仍受滑块类型限制：整数型滑块不接受小数，且会自动取整）。多数滑块右侧会显示当前数值，可用来核对。

问：编辑器模式的界面太小或太大？

答：UI 缩放（UI Scale）保存在 .axiominternal.hocon 的 globalScale 项中，可以按显示器分辨率与个人习惯调整。

问：翻译（文本）不完整或显示异常？

答：.axiominternal.hocon 中的 lastTranslationCount 与翻译数量相关；如遇显示问题，可参照官方文档与社区资源核对。

问：商业项目里用 Axiom 需要注意什么？

答：先判断是否属于商业用途，再决定是否需要白名单或商业授权。官方白名单页面明确区分了「什么算商业用途」与「什么不算商业用途」，商业授权页也列出了授权包含的功能范围与获取方式，请以该页为准。

问：游戏规则命令怎么用？

答：Axiom 新增了 axiomDoBlockDrops、axiomDoBlockGravity、axiomDoTrampleFarmland、axiomPlayerInvulnerability 四条游戏规则。官方文档只给出了名称与效果描述，未给出完整命令写法与默认值，实际使用时请以游戏内自动补全为准。
